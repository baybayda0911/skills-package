# Skills Package

一套持续积累的个人 AI 技能集合，旨在改善 AI 的思考过程、提高工作效率，并帮助它输出更清晰、可靠、可执行的结果。

这里的技能（Skill）是一份可重复使用的工作说明：告诉 AI 何时使用、怎样推进任务、需要检查什么，以及何时停止。它不是模型本身，也不是独立运行的应用程序。

## 仓库用途

- 把有效的提问方法、思考步骤和输出要求整理成可复用技能，减少每次重新编写提示词的工作。
- 集中维护技能正文、参考材料和模板，让改进有记录、文件容易查找。
- 按任务选择需要的技能，而不是让所有规则同时参与每一次工作。
- 尽量减少对特定项目和本机环境的依赖，便于迁移到其他项目或支持技能的 AI 工具。

仓库不限于某个技能或某类项目。后续可以加入规划、研究、写作、开发、检查和日常工作等方向的技能；这些是扩展方向，不代表目前均已提供。

## 技能清单

| 技能 | 用途 | 使用说明 |
| --- | --- | --- |
| `idea-refiner` | 澄清关键选择、挑战假设并收敛为可审阅方案或小规模验证计划 | [技能入口](skills/idea-refiner/SKILL.md) |
| `ten-step-learning` | 共同十步、六类可组合任务配置与持续训练，支持诊断、示范、练习、证据评价、延迟复验、开课导学与共享文件记忆（v3.2.5） | [技能入口](skills/ten-step-learning/SKILL.md) |

每个技能的适用条件、工作流程和模板都保存在自己的目录中。根目录 README 只介绍整个仓库及通用使用方式。
`idea-refiner` 的记录交接、领域补充与对照演练方法按需加载；普通讨论不需要完整模板或评测流程。
`ten-step-learning` 先给目标、诊断状态、骨架和示范练习样品，确认后展开研究手册或当前单元训练。测试、解释和复习穿插全程；资料生成不代表用户已掌握。Codex/Trae可读取同一用户共享学习目录的档案与课程进度，按锁与旧内容校验交接保存；不自动发现目录或同步安装。详见[使用说明](skills/ten-step-learning/README.md)。

## 快速使用

### 1. 获取仓库

在你希望保存仓库的父目录运行：

```bash
git clone https://github.com/baybayda0911/skills-package.git
```

已有本地副本时直接使用，不需要重复克隆。下载或克隆文件不等于安装技能。

### 2. 选择并加载技能

先从技能清单找到合适的条目，阅读对应 `SKILL.md` 中的适用条件。

- 工具支持本地技能安装时，将选中的 `skills/<skill-name>/` 整个目录安装到该工具要求的位置，保留其中的相对路径。
- 工具能读本地文件但不支持技能安装时，明确请它读取对应 `SKILL.md`，再按正文要求读取有关参考材料。
- 工具不能读本地文件时，需要提供技能正文及任务所需的参考材料；仅提供文件路径不会让它获得文件内容。

不同工具的安装目录、加载方式和调用语法可能不同，请以对应工具说明为准。本仓库目前不提供一键安装器，也未验证跨工具自动发现。

### 3. 提供具体任务

支持 `$技能名` 调用的环境，可以使用下面的形式：

```text
请使用 $idea-refiner 完善我的构思：……
本次只讨论并形成方案，不开始实施。
```

需要系统学习一个陌生领域时：

```text
请使用 $ten-step-learning 按十步法带我学：……
我目前零基础，想独立完成的任务是：……
采用持续训练；每周可投入……小时，先给骨架和示范练习。
```

该技能按需集中补齐用途、目标任务、起点、预算和资源。骨架提供新十步导航、第4步完整示范与第5步短练习；研究模式的学习成绩保持未观察，训练模式依据实际作答和产物推进。需要只研究领域时，可明确说“采用研究与规划模式”。

在已安装且支持技能发现的助手中，也可以直接说“使用完善构思技能”或“使用 idea refiner”，再说明你的想法；两者均指 `idea-refiner`，不改变规范技能标识。

不支持上述调用方式、但能读取文件的助手，可以这样使用：

```text
请读取 skills/idea-refiner/SKILL.md 和其中与任务有关的参考材料，
按该技能说明帮助我完成下面的任务：……
```

第二个示例的路径相对于仓库根目录；在其他工作目录中使用时，应提供实际可访问的文件位置。

描述任务时尽量说明目标、现有材料、主要限制和期望交付物。使用技能不等于授权购买、对外发送、删除、安装或发布等行动。

## 文件组织

根目录保存仓库级说明与规则，`skills/` 保存各个技能：

- [README.md](README.md)：仓库用途、使用方式和技能清单。
- [AGENTS.md](AGENTS.md)：维护本仓库时的协作约定。
- [.gitignore](.gitignore)：本机配置和临时文件的忽略规则。
- [LICENSE](LICENSE)：仓库许可证。
- `skills/<skill-name>/`：一个技能对应一个独立目录。

技能目录采用以下约定，只有 `SKILL.md` 必需，其余按实际需要添加：

| 文件或目录 | 作用 |
| --- | --- |
| `SKILL.md` | 技能入口，包含名称、适用条件和工作步骤 |
| `references/` | 按需读取的补充说明或模板 |
| `scripts/` | 技能需要的可执行辅助脚本 |
| `assets/` | 可直接使用或复制的素材 |
| `agents/` | 特定工具支持的展示或配置文件 |

`scripts/`、`assets/` 等是可选约定，不表示每个现有技能都包含它们。仓库源码目录也不是工具的自动安装目录。

## 添加与维护

1. 在 `skills/` 下创建技能目录，使用小写英文、数字和单连字符命名。
2. 编写 `SKILL.md`，保持其中的 `name` 与目录名一致，明确适用条件和不适用情况。
3. 按需添加参考材料、模板或脚本，避免复制无关规则和私人资料。
4. 检查格式、相对引用和使用示例，再用真实任务或脱敏场景验证效果。
5. 更新根目录技能清单，保留第三方来源与适用的版权声明。

维护前先阅读 [协作约定](AGENTS.md)。文件格式正确不代表实际任务效果已验证，验证结论应区分结构检查、对话演练和真实运行。

## 限制与安全

- `ten-step-learning` v3.2.1补齐导学通俗表达：简短点名后用具体学习经历解释，模板与说明书同步；第4/5/6步含义及评价条件保持。v3.2新增的开课导学包括昵称与学习者确认、系统介绍、分轮偏好初访、本课程学习约定及中断续接；保留十步、任务配置、评分/结业与共享文件保存协议。v3.2、v3.1完整校验快照及v3.0和更早记录继续保留；昵称不是身份认证。对照演练不代替真人学习或真实两端运行验证。详见[说明书](skills/ten-step-learning/README.md)及[设计规范](skills/ten-step-learning/references/设计规范.md)。
- `ten-step-learning` v3.2.2新增四条检查：**可考性门槛**（计分题所考点须有示范或练习、或在两处不同性质材料中用过、或属规定型且显式列为记忆项；否则标"探测题"只记不计分）、**同一检验不得重复判分**、**占位假设不得升格为条件**、**两种模式是串联而非二选一**。四条均来自真实学习会话的反馈（超纲题被申诉、前后两题重考同一事实、助手自填的预算被后续文档当成条件、两模式被读成并列选项），只约束"什么能考、怎么问、假设怎么记"，不提高也不降低任何分数线，**不足以据此宣称学习效果改善**。本次仅更新仓库源码与 WorkBuddy 副本；Trae 全局与项目级副本待版本调整结束后统一同步，且不提交、不推送。详见[说明书](skills/ten-step-learning/README.md)。
- `ten-step-learning` v3.2.3新增**课后提问与疑问台账**（提问不计分、不建证据、不改变状态；只有复述/追问可作证据；单元小测只从"已澄清未复述/仍存疑"中抽 1 题）与**集中输入三段结构**（核心一句 → 易混淆对照，两列并置各带实例与反例 → 常见错法及为什么错；只提醒不对比等于没教，且提示中出现的内容即属"已教"、可以考）。两条均来自真实会话反馈：学习者主动追问条文结构才暴露教学缺陷；把"权限类别"记成"具体策略"则说明只说"都算"不构成对照。不提高也不降低任何分数线，**不足以据此宣称学习效果改善**。本次仅更新仓库源码与 WorkBuddy 副本；Trae 全局与项目级副本待版本调整结束后统一同步，且不提交、不推送。详见[说明书](skills/ten-step-learning/README.md)。
- `ten-step-learning` v3.2.4新增**记号与公式的交付前提**：任何公式／记号在用于下结论前须先给**符号表（含义＋单位＋数值）→ 它要回答什么 → 一次数值走查**，缺一不得进入结论；每个机制须给"没有这条规则会怎样"的具体情形；反例须写出"按错误理解差几倍"；只作了解的公式显式标注"不进考核"；并增加交付前自检（找未定义的符号，补或删）。触发它的是**一次真实教学事故**：输入在未定义符号的情况下直接给公式并推结论，学习者反馈"完全理解不了"；同一次输入给出熔断两条件却无实例，同样被反馈"看不懂"。**该次输入被判定作废并重做**（未作答、无成绩，故不涉及成绩改写）；本条不改变任何分数线，**不足以据此宣称学习效果改善**。本次仅更新仓库源码与 WorkBuddy 副本；Trae 全局与项目级副本待版本调整结束后统一同步，且不提交、不推送。详见[说明书](skills/ten-step-learning/README.md)。
- `ten-step-learning` v3.2.5新增**改写已有材料的保值规则**：重写／精简／替换既有教学内容前，**先问**学习者旧版「已教要点清单」是否已学完；未学完须**逐条核对**是否保留，不得整块替换；删除须显式写「**该项退出教学**」并留痕，不得静默消失；且**退出教学的点不得再进计分题**。触发事实：一次输入因"公式未定义"作废重做，重写时把旧版"交易时段"整块漏掉却仍照考，学习者作答后才暴露"没教就考"——该题当场标为探测题、不计分。**"先问"这一步由学习者本人提出**：作者原稿只要求"删除须标注"、默认必须保留，会把已学透的冗余一路滚下去。本条不改变任何分数线，**不足以据此宣称学习效果改善**。本次仅更新仓库源码与 WorkBuddy 副本；Trae 全局与项目级副本待版本调整结束后统一同步，且不提交、不推送。详见[说明书](skills/ten-step-learning/README.md)。
