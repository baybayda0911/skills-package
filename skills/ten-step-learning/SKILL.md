# 十步学习法

以目标任务和真实表现组织学习。共同十步保持不变，按任务选择六类可组合配置；不承诺一份手册、固定小时数或一次测验让人精通。

## 启动与任务选择

- **研究与规划**：设计地图、示范、练习、评价和资源；学习表现记未观察。
- **持续训练**：按[文件记忆](references/文件记忆.md)定位共享学习目录和课程，读取学习者档案、有效偏好及进度，核对续学摘要后处理待答/补救；示范、练习、反馈、复验并记录真实产物。未配置共享目录时仍可沿用单课程进度。

两者是**同一条流程的先后两段，不是二选一**（v3.2.2）：正常顺序是先设计与确认（领域地图、示范、材料、评价标准），再进入训练、按真实产物记录。**“模式”只决定要不要把表现记成绩**——还没动手时记“未观察”，动手之后才进台账。新课程默认按此串联推进；只有用户明确“只要方案/先别练”时才停在规划段。

“带我学/开始练习”通常选训练，“只要报告/先规划”选规划。新学习者、新课程、身份疑问或导学未完成时，读[开课导学](references/开课导学.md)：核对称呼与学习者，简短介绍系统，分轮只补用途、目标、基础、预算、条件及偏好，交付本课程学习约定。已给信息不重问，可匿名或明确略过；普通续学接回已记录的I初访问题或实际教学待答。

导学、初访与课程约定按[通俗表达规则](references/开课导学.md)先简短点名，再用具体学习动作解释；专业名称与含义相连，不照读内部字段或只列十步标题。

初访信息足够就开始当前阶段，不穷尽习惯。昵称不作认证；换人先确认独立个人目录，改称呼保留稳定ID。未回答实际诊断仍记待诊断，初访与完成导学不计专业成绩。

先读 [任务配置](references/任务配置.md)，按**目标产物与合格依据**选主配置，必要时组合辅助配置，再只读选中的详细配置。职业/学术/商业负责找外部任务标准，概念/操作/判断负责识别能力成分，不能替代具体任务配置。

| 配置 | 何时使用 | 详细指引 |
|---|---|---|
| P1 形式推理与证明 | 结论要由定义、前提和推理规则成立 | [P1](references/任务配置/P1-形式推理与证明.md) |
| P2 经验解释与探究 | 需要数据、测量、模型与经验检验 | [P2](references/任务配置/P2-经验解释与探究.md) |
| P3 文本与史料解释论证 | 需要受材料和语境约束的解释 | [P3](references/任务配置/P3-文本与史料解释论证.md) |
| P4 工程设计 | 需要在需求与约束中实现、比较和测试 | [P4](references/任务配置/P4-工程设计.md) |
| P5 沟通与互动 | 合格表现依赖受众、情境和对方回应 | [P5](references/任务配置/P5-沟通与互动.md) |

同一学科可组合不同配置；不要求每个单元跑完六类，也不让初学者自行选择教学术语。选择理由和未验证条件写入进度。详见 [领域适配](references/领域适配.md)。

## 共同十步

| 步 | 功能 | 最小产出 |
|---|---|---|
| 1 | 目标与能力标准 | 终点产物、配置、条件、关键错误、判据和预算 |
| 2 | 起点与先修诊断 | 实际短任务、先修依赖、误解及工具缺口 |
| 3 | 最小领域地图与核心机制 | 必要结构、三级索引、稳定ID、含义与用途 |
| 4 | 标准任务示范 | 可核验的产物、过程、选择理由和检查方法 |
| 5 | 引导练习与指导渐撤 | 按表现提供/缩减支持，记录实际提示 |
| 6 | 独立实践与反馈补救 | 本人产物、按判据反馈、补救后新任务 |
| 7 | 变式、证据与批判判断 | 条件变化、方法选择、各类证据与失效边界 |
| 8 | 综合评价与陌生任务 | 相关能力组合运用与有限范围结论 |
| 9 | 延迟复验与自我解释 | 间隔后新表现、保持结果、复习动作 |
| 10 | 工作支持与持续成长 | 速查、作品/错误记录、反馈渠道与后续路线 |

这是十项教学功能，不是一次性线性章节。初学新任务默认“最小地图与机制→完整示范→跟做/补全→独做→反馈→变式→延迟”；已有同任务族、同条件独立证据可缩短冗余，记录依据。配置可以安排需求/现象/作品导入和有限探索，但不能让零基础者无指导发现全部知识。证据判断、解释、复习从早期穿插。细化时读 [各步检查](references/各步必答问题清单.md)。

## 教学、评价与进度

范围信息足够后用[骨架模板](assets/骨架模板.html)交付本课程学习约定、目标、诊断状态、配置、地图和示范练习样品；范围、负担和表达尚需决定时保留待问。已有明确认可或开始指令不重复确认；约定未获回答不记为认可。用户要求纯文本等形式时按要求交付。

依据当前先修、实际表现、任务复杂度和负担调整支持。初/中/高阶 8∶2、6∶4、5∶5保留为**可调预计时长预设**，不机械决定每轮活动。学习活动中的短提取不等于结业考试，不因比例推迟必要检查。

保留“小节练习—单元小测—板块综合”三级检验功能；任务形式由配置与目标决定，**不设跨领域统一题型配额**。90/80/75保留为可调数值预设；评分量规须有意义，声明权重、得分档和关键错误。不能可靠量化时先声明分维度达标判据。分数不证明独立性，有提示只记录辅助表现，关键错误不被总分抵消。

**出题前先问两句（v3.2.2）**：这个点**在哪里教过**（示范、练习，或两处不同性质材料用过）？同一份检验里**有没有别的判分点考同一事实**？教过但强度不足的标为“探测题”只记不计分；重复的合并或拆开。细节见 [深度标准](references/深度标准.md) §4 与 [交互与状态](references/交互与状态.md) §3。

**公式先讲后算（v3.2.4）**：出现公式或记号时，先给**符号表（含义＋单位＋数值）→ 它要回答什么 → 一次数值走查**，三者缺一**不得下结论**；每个机制要给出"没有这条规则会怎样"的具体情形；反例要写出"按错的理解会差几倍"；只作了解的公式显式标注"不进考核"。交付前自检一遍：有没有未定义的符号。细节见 [深度标准](references/深度标准.md) §6。

**改写旧材料要先问（v3.2.5）**：重写、精简或替换既有教学内容前，把旧版「已教要点清单」交学习者问一句"是否已学完"；未学完须**逐条核对**是否保留，不得整块替换；删除须显式写「**该项退出教学**」，且**退出教学的点不得再进计分题**。细节见 [深度标准](references/深度标准.md) §6。

**讲清与提问（v3.2.3）**：新内容成块交付按「**核心一句 → 易混淆对照（两列并置，各带实例与反例）→ 常见错法及为什么错**」组织，只提醒不对比等于没教；提示中出现的内容即属"已教"，按可考性门槛可以考。每小节末留**可选**提问口，问答记入进度文件的**疑问台账**——提问不计分、不改变能力状态，只有复述/追问可作证据；单元小测只从「已澄清·待复述」「仍存疑」中抽 1 题，已复述者不再抽。细节见 [深度标准](references/深度标准.md) §6 与 [交互与状态](references/交互与状态.md) §3。

按 [深度标准](references/深度标准.md) 设计任务、评分与进阶，按 [交互与状态](references/交互与状态.md) 的唯一规则记录：
- 小节局部通过、单元结业、板块里程碑**分别判定**；单元/板块须同时满足所辖必需能力和对应综合检验，不由总分批量升级所有小节。
- 历史即时通过、当前保持、迁移和真实工作分别保存；延迟失败记已发生的失败与需补救，不能仍称“待复验”，也不抹去历史。
- 三级索引负责定位，独立的先修关系和建议路线负责调度；只有确实未满足的必要先修才是欠账。
- 每轮读取[进度文件](assets/学习进度模板.md)，有实际状态变化才保存，附当前位置、分状态计数、下一动作和证据ID；课程内的续学摘要只是缓存，不能覆盖原台账。
- 共享入口用[学习者档案](assets/学习者档案模板.md)保存稳定ID与可变称呼、系统介绍记录、课程索引、明示偏好、观察/待验证假设及变更记录；能力/证据引用带学习者与课程范围。私人文件保存在用户工作目录，Codex/Trae使用同一目录。
- 保存遵循[文件记忆](references/文件记忆.md)的单写者、锁与旧内容校验协议；冲突先重读，不强制覆盖。课程先保存、索引后同步；不可写或不能执行协议时给可复制更新并说明未落盘。

## 准确性与交付

按 [证据规则](references/证据规则.md) 核验关键知识、参考解与评分。来源可查不等于AI讲解/判分正确；等价解、边界答案、反馈不确定性和需领域复核项必须可见。独立评价不提前给答案，求助后转练习，另用新任务确认独立性。通常一次给一个待答任务。

用 [报告模板](assets/报告模板.html) 交付 `<领域>_十步法学习手册.html`，计划和实际结果分栏。模板样式自包含、保留必要来源链接、清除占位符；训练逐单元保存，未来章节标计划。用 [地图模板](assets/进度地图模板.html) 首次生成 `<领域>_学习进度地图.html`，以后只在用户要求时更新，注明切片日期；当前进度以Markdown记录为准。

投资、法律、医疗、税务个体决策保持学习/模拟定位；实物、现场、资格或监督不足时列出外部验证要求。私人原始作答留在用户工作目录，不进入技能源码。维护与基线比较见 [设计规范](references/设计规范.md)。
