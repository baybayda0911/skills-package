# 十步法学习引擎 v2.0

以目标任务和学习表现驱动进阶。生成完整资料与学习者形成能力分别记录，不承诺一份报告、固定小时数或一次测验使人精通。

## 模式与开局

- **研究与规划**：建立领域地图、证据、示范、练习设计和路线；可以交付完整 HTML，学习表现标为“未观察”。
- **持续训练**：用户实际作答或操作，逐单元诊断、示范、练习、反馈、复验；HTML 作为可更新的学习手册。

“带我学/开始练习”通常选持续训练；“只要报告/先规划”选研究与规划。请求含糊时简短澄清模式，可同时准备已有信息支持的范围和目标，不代替用户回答诊断题。

集中补齐影响路径的缺失信息：目标领域与实际用途、期望完成的任务和层级、已有基础、时间预算/工具/材料、模式与输出位置。沿用已提供答案；用户尚未作答时可明示规划假设，但诊断和学习成绩保持未观察。

长期目标不因零基础封顶；先修、任务复杂度、信息量、指导和节奏要按当前表现调整。先用 [领域适配](references/领域适配.md) 选相应层级的外部任务标准；按 [深度标准](references/深度标准.md) 建立目标—教学—练习—评价映射。

## 新十步（编号唯一依据）

| 步 | 名称 | 核心结果 |
|---|---|---|
| 1 | 目标与能力标准 | 范围、终点任务、工具/提示条件、关键错误、验收依据与预算 |
| 2 | 起点与先修诊断 | 自报信息加实际短任务，确认先修、误解和资源缺口 |
| 3 | 最小领域地图与核心机制 | 必要概念、关系、流程、适用边界与即时资源 |
| 4 | 标准任务示范 | 正确产物、完整过程、关键选择理由与检查方法 |
| 5 | 引导练习与指导渐撤 | 跟做/补全到相似独做，依表现减少支持 |
| 6 | 独立实践与反馈补救 | 用户产物、按判据反馈、补救后新任务验证 |
| 7 | 变式、证据与批判判断 | 辨认适用条件，按领域引入真实角色、争议与反证 |
| 8 | 综合评价与陌生任务 | 对目标任务族的独立表现和迁移作有限范围判断 |
| 9 | 延迟复验与自我解释 | 间隔后回忆/解释/新任务，更新保持证据与复习计划 |
| 10 | 工作支持与持续成长 | 个人速查、作品/错误记录、下一阶段任务和反馈来源 |

细化任务时读 [各步必答问题清单](references/各步必答问题清单.md)。这是执行框架；先修与表现决定实际路径，允许已有独立证据者跳过冗余。第 8、9 步是综合检查点，检查、自我解释与复习从第 3 步起穿插，不等手册完成才开展。

## 骨架与样品

用 [骨架模板](assets/骨架模板.html) 给出目标、先修/待诊断项、任务映射、十步导航和关键缺口。样品改为第 4 步完整示范加第 5 步短练习；研究模式仅设计练习，训练模式收集用户尝试。样品可以用于教学，也不能伪造用户完成记录。

请用户整体确认范围/任务、时间与资源、样品的表达和指导方式，允许局部修改。完成确认后展开研究手册或开始当前单元；已明确认可的范围无需重复询问。用户可缩小目标、暂停或选择仅要规划。

## 每单元学习循环（持续训练必做）

必要机制 → 完整示范 → 解释关键选择 → 补全练习 → 相似任务独做 → 反馈补救 → 变式任务 → 延迟复验。

按照 [交互与状态](references/交互与状态.md) 跟踪提示和任务证据。示范可展示完整解法；练习先看用户尝试再分层提示；独立考核阶段不提供答案或代写成果。中途请求帮助可切回练习，但此次不能标为独立通过。

通常一次给一个待答任务，避免提前泄露后续答案。失误先分辨先修缺口、概念误解、步骤错误或表达问题；针对反馈后用不同任务复核，不靠“我懂了”进阶。提高复杂度时可重新增加指导。未通过不无限重复同一题：换示例、补先修、缩小任务或暂停并记录。

## 评价与状态

课程规划覆盖、即时独立表现、延迟保持、迁移、真实工作表现分开报告。关键能力分别设通过条件；不能用总体比例抵消关键错误。知识的证据质量与人的能力判据分别评价。

每次训练或续接先读工作目录的 `学习进度_<领域>.md`，无文件则按 [学习进度模板](assets/学习进度模板.md) 新建。记录已讲解、提示下完成、独立通过、延迟通过、迁移通过及产物依据；“已讲解”不等于掌握。未做延迟/真实工作检验时标未验证，不因即时答对跳过复验。调整版本或目标时保留旧记录，重新映射能力 ID，不按旧题号续接。

## 证据与交付

关键事实、规范、公式、效果与争议按 [证据规则](references/证据规则.md) 绑定来源。无联网时给可检索线索并标待核实，不能编造链接。角色、争议、反例和资源数量按任务需要选择，不为配额创造内容；没有通用10/7/4/1可信度分或85%能力认证线。

用 [报告模板](assets/报告模板.html) 交付 `<领域>_十步法学习手册.html`：沿用内置样式、资源自包含、清除占位符，保留必要来源超链接。研究模式可分批构建十章；训练模式按当前单元更新，未来内容标为计划，不把生成批次作为学习完成证据。每批/单元落盘 Markdown 与进度，避免中断丢失。交付给出下一可执行动作和待验证项。

投资、法律、医疗、税务的实际个体决策采用知识学习与模拟路径，说明适用边界；需要现场操作、资格或专业监督的能力明确记录外部验证要求。敏感原始作答和私人业务资料留在用户工作目录，不进入技能源码。

维护者查看 [设计规范](references/设计规范.md)，了解研究依据、旧编号映射、v1.1 基线和验证边界。
