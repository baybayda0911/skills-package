# 十步学习法 · v3.3.1

用共同十步组织专业学习，再按目标产物配置教学、练习和评价。既可先规划，也可持续带练；资料生成、即时独立、延迟保持、迁移和真实工作分别记录。

## 怎么启用

可以说“按十步法带我学……”“用十步法拆解……”“使用 ten-step learning”。说明用途、希望完成的任务、已有基础、预算与工具条件即可；不必自己选教学类型，也不必先列完整课程。

- “按十步法带我学数学证明，我懂基础代数，每次20分钟。”
- “用十步法教我分析历史材料，先给一个示范，再让我试。”
- “按十步法规划照片整理脚本的学习路线，当前没有运行环境。”
- “用十步法帮我练酒店入住英语，目前只能文字聊天。”
- “只要研究与规划，暂不开始训练；请给学习手册。”

工具需已加载本技能；仅说一个本地路径不会让无文件权限的工具获得内容。完整安装目录须包含入口、配置、全部参考/模板，并保留[MIT许可](../../LICENSE)。本仓库源码不等于全局安装副本，改源码不自动升级任何工具。

## 新课程怎样开始

新学习者先问可匿名的昵称并给一屏系统介绍，再按回答分轮补齐目标、条件与偏好，交付本课程学习约定，然后进入短示范与实际诊断。已知信息不重问；普通续学接回原任务，导学中断则接回待答问题。详见[开课导学](references/开课导学.md)。

- 初访默认两轮，必要时补一轮，信息足够即停止；可说“先体验、以后再调”或“跳过问卷”。不要求给自己选学习类型。
- 可调整称呼、表达、例子、篇幅、节奏和帮助方式；范围/评价安排结合目标事先协商。独立性、真实结果和关键错误如实记录。
- 学习约定说明阶段目标、基础来源、路线与预算、偏好范围、评价条件及待决定事项；暂定交付不等于用户明确认可。
- 旧课局部偏好不自动成为新课确认设置；教学观察和待验证假设也不自动成为长期偏好。
- 改昵称保留稳定学习者ID；换人须用独立个人目录。昵称确认依赖用户声明，不是登录认证或自动换人检测。
- 档案保存已介绍主题，课程保存导学状态、I初访问题与约定；导学完成不记专业成绩，也不把访谈算作练习。

只想了解系统时不强制建档或训练；已有v3.1课程缺导学字段可继续学习，不强迫补走第一堂课。可直接说：“叫我小禾，先介绍系统，再逐轮了解我的学习需求。”

开课时可以先说“第6步叫独立实践与反馈补救”，紧接着说明：“这回换一个类似任务，请你先自己做。我看你卡在哪一步，就帮你补上，再换题请你自己试。”前面“我做给你看、陪你练”分别主要是第4、5步。短版介绍先讲学习经历，想看完整十步时再展开；不会把专业名词和管理编号一股脑报给初学者。

## 两种模式和十步

先准备当前一段必要的学习安排、材料和检查条件，再进入示范、练习和反馈；只想先看方案可以停在“研究与规划”。“持续训练”也包含不计分的练习，仍如实记录实际表现。大课程分段准备，不等整本教材完成才开始，已明确的要求不重问。

| 步 | 名称 | 这一段会怎么学 |
|---|---|---|
| 1 | 目标与能力标准 | 先聊清楚你想学来做什么，再说好：最后能自己做成什么，就算这一段学会了。 |
| 2 | 起点与先修诊断 | 先看看你已经会哪些，再试一小段，从适合你的地方开始；暂时做不出来也能帮我们找到起点。 |
| 3 | 最小领域地图与核心机制 | 先给你看一张简单路线图，讲清眼下要用的几个道理；其他细节用到时再补。 |
| 4 | 标准任务示范 | 我完整做一遍给你看，边做边解释为什么这样选、哪里容易错、做完怎样检查。 |
| 5 | 引导练习与指导渐撤 | 轮到你动手，我在旁边陪着；卡住先给一点提示，熟悉以后就逐渐少帮一点。 |
| 6 | 独立实践与反馈补救 | 换一个类似任务，先按说好的条件让你自己完成。我看具体做法，找出卡住的那一步；补上后再换题让你自己试。 |
| 7 | 变式、证据与批判判断 | 换个条件、资料或场景试试，看看原来的办法还管不管用，也说说为什么这样做有道理。 |
| 8 | 综合评价与陌生任务 | 把前面学过的几件事放进一个没做过的新任务，看看你能不能把它们连起来用。 |
| 9 | 延迟复验与自我解释 | 过几天再换个例子，看看还能不能做，并用自己的话说说为什么，帮助找出需要再练的地方。 |
| 10 | 工作支持与持续成长 | 把常用办法、容易忘的地方整理成速查笔记，以后真要用时能找到，再商量下一段学什么。 |

保留v2.0以来的十步顺序，把它视为可循环的教学功能。地图、必要机制先建立；需求/现象/整体作品可作导入，证据判断、解释和复习从早期穿插。具体先修、指导与任务由诊断决定，不让所有人机械跟做同样流程。

## 行动卡、课程样品和教师参考是什么

它们是共同十步的教学材料，不是额外步骤：[教学材料与行动卡](references/教学材料与行动卡.md)。行动卡让你知道眼下做什么、怎样检查和卡住去哪补；完整样品展示一段课怎样讲、练、反馈；排障卡给出从现象到检查的动作；教师任务关联把题目连回教过的材料和版本，防止未教就考。

可说“我只有8分钟，先做成一件小事”“别讲整本，给我当前行动卡”“按我卡住的现象找一个检查”“这个检查依据哪段教材”。先试一点或充分了解都可，实际短任务才确认能力。路线、按问题找例子、用时速查指向相同材料，进度仍区分阅读、辅助、独立、延迟与迁移。

完整原创[照片整理学习材料](assets/课程样例/照片整理_学习材料.md)与另交教师的[参考](assets/课程样例/照片整理_教师参考.md)展示纸面小单元；它不是已运行程序或真人成绩。这里的“教师”通常指带你学习的agent，维护者也可审阅：教师参考是填好的示范答案、判据与反馈，教师[任务卡模板](assets/教师任务卡模板.md)是agent给当前课程备课用的空表。学习者主要看行动卡、讲解、示范、任务和检查条件；独立检查前不随题面交付教师答案，已看过就转练习并另题确认。教材的符号先解释，计算才补适用单位/数值，文本、证明和互动用自身的例子解释错误后果，不强编倍数。

## 六类可组合任务配置

| ID/类型 | 主要产物与判据 |
|---|---|
| P1 形式推理与证明 | 定义/前提下的有效推理、证明和反例 |
| P2 经验解释与探究 | 与设计、测量、数据及不确定性相符的解释 |
| P3 文本与史料解释论证 | 受语言、来源、材料与语境约束的论证 |
| P4 工程设计 | 满足需求与约束，具有测试/迭代证据的产物 |
| P5 沟通与互动 | 情境中的理解、回应、澄清与共同任务 |
| P6 创作、表演与操作 | 分子类型评价作品、表现或实际动作与检查 |

详见[任务配置](references/任务配置.md)。按任务选，不按文理工贴标签；同一学科可组合配置。P3继续区分历史/文学/规范论证，P6继续区分创作/表演/操作。AI给选择理由，再据表现调整，不让初学者选择抽象教学法。

## 学习、评分与进度怎样工作

通常先交骨架、最小地图和示范练习样品，确认范围/负担后展开。每单元用“必要机制—示范—适量支持练习—独立—反馈新任务—变式—延迟”循环。通常一次一个待答任务；已有相关独立证据可缩减冗余，遇到新困难再增加帮助。

三级索引用于知道“学到哪”，稳定能力ID与证据用于知道“会什么”，先修关系与建议路线独立保存。默认按路线推进；跨编号可能是豁免、非依赖分支或真实待补先修，不一律算欠账。

| 检验 | 默认条件 | 可调数值预设 |
|---|---|---|
| 小节练习 | 可提示，记录实际支持 | ≥90% |
| 单元小测 | 无教学提示，按声明工具条件 | ≥80% |
| 板块综合 | 无教学提示，陌生组合任务 | ≥75% |

数字来自使用偏好，不是普适科学线。按真实量规、权重与得分档计算；5—9个等权二元点在90%下仍只能全对，不能靠“至少5点”解决。必要时预设有意义的部分分，确需全对就明说。不能可靠量化时评价前声明分维度达标。

提示下高分只说明辅助表现；独立通过还须满足必要判据、没有关键错误。单元结业需所辖必需小节当前可用且单元检验通过；板块还须相关单元结业和综合通过。总分不能覆盖局部关键失败，不要求所有领域凑固定题型比例。

历史即时通过、当前保持、迁移和真实工作分别保存。延迟失败保留过去的通过，同时填写实际失败与当前需补救；地图不继续显示无缺口的绿色有效达成。未发生的复验保持待验证，无调度工具不声称自动提醒。

8∶2/6∶4/5∶5保留为初/中/高阶的可调预计时长预设，辅助安排节奏；学习者基础和实际表现优先，不用材料份数除作答次数，不逐轮硬算。三级检验和任务配置不因该比例推迟必要检查。

## 常用技巧

- 用具体目标收敛范围：“能解释一组数据”“能提交一个带测试的脚本方案”，比笼统说“精通”更容易设计当前阶段。
- 说清现实条件：文字聊天、仿真、实物和现场表现能支持的结论不同。
- 卡住时说出已尝试和卡点，助手可给适量提示；另用新任务确认独立性。
- 续接时给出已配置的共享学习根和课程名，先处理待答/补救/复验；只用单课程文件也可续学。
- 可要求更换示范、缩小任务、改变节奏或评价前调整默认设置；旧成绩保留原条件。
- 对开放答案可要求说明判据、接受哪些等价解、哪些评分需要专业复核。

## Codex、Trae怎样共享记忆

首次说：“把这个目录作为我的共享学习目录，请记录学习者档案、课程索引和续学摘要。”换工具时说：“读取同一共享学习目录，继续××课程。”两端须能读写该目录并加载支持v3.2导学及v3.1文件记忆的技能；这是文件交接，不依赖同一聊天，也不自动安装或同步技能。

根目录只放一个`学习者档案.md`，集中管理课程入口、用户明示偏好、观察/待验证假设和变更记录；各课放`courses/<course-id>/学习进度.md`，保留原始作答、A/E证据、当前缺口与续学摘要。偏好可说“仅本课程”“本周有效”“撤回旧偏好”；未声明范围默认本课，明确跨课通用才记全局，当前明确要求优先。图解偏好不等于固定学习类型。索引不存成绩，摘要不覆盖台账，不把示范、假设或未来复验当实绩。

先在一端结束保存，再到另一端续学。两端均用随技能附带的本地Python 3.9+保存助手，按旧内容哈希和共享锁检查冲突；锁存在或文件已变就停写核对。没有Python或写权限时继续教学并给可复制更新，明确未落盘。课程先保存、索引后刷新，部分失败会标出待同步。目录未给出时只补问位置，私人数据不存进全局技能副本或公开仓库。不接Hindsight、数据库或后台提醒。

详细协议与旧版接入见[文件记忆](references/文件记忆.md)。旧进度先保留原件再登记唯一活动副本，不改原成绩或补造未知条件。没有配置共享入口时，原单文件流程仍可用。

## v3.3.1：教法、资料核验与续学细则

按DeepTutor评审的16项建议补强现有机制，版本规则见[设计规范](references/设计规范.md)。你可以直接说：

- “刚才的比喻没帮上忙，换一种解释，先直接讲清楚。”助手按具体卡点换讲法，只记录有据且有用的局部反馈；听懂自述不替代独做。
- “先给一点线索，实在卡住再完整示范。”帮助可按需要加减，不必固定反问几轮；独立检查中求助后另题确认。
- “这题可能判错了，请查原题、原答和依据。”核实后更正/作废原判，并复核受影响路线；未安全保存的只是更正草案。
- “今天只有几分钟，先接回待答，再安排最该复验的一点。”助手核最新记录及相关原答，不把旧摘要当掌握结论。
- “我们共用这套教材，各自保存学习记录。”仅在明确授权材料位置时复用教材版本；不同人仍分根，昵称相同不合并成绩。

资料逐项说明用途和缺口；题干与参考解共同核具体来源/推导/测试。已选、读过、交付、可考与掌握分开。读图目标实际核原图；允许的坐标和题目数据不自动算提示，直接答案线索则如实记帮助。按内容选择图示/走读/短互动，纯文本也能学。

教材改版给出受影响要点、题目、先修、速查及旧证据说明；已明确学完/未完/退出不重复问。现有模板补相应字段，旧课按需补、未知仍未知，不强制每轮填全表。教学教法、错因和结果用原F/O/H及A/E，不新增数据库、状态算法或后台服务。

本轮属于既有规则/字段补强，按现行约定升为v3.3.1；保留v3.3 Git标签与改前完整校验快照作直接基线。共同十步、六配置、三级检验、可调90/80/75、结业条件和保存协议保持。对照范围与实际结果由本次管理报告交付，结构、AI演练和真人效果分别报告。源码修改不自动发布、打新标签或升级安装副本。

## v3.2.2出题前检查

新增四条纪律，都落在既有机制内、不改十步与模板结构：

- **可考性门槛**：计分题所考点须有示范或练习、或在两处不同性质材料中用过、或属“规定型”且已显式列为记忆项；否则标**探测题**，只记录不计分、不触发需补救。出题前逐题写明“该点在何处教的”。
- **同一检验不得重复判分**：两个判分点不得考同一事实；天生易混的一组合并对比着问，或分开各问一处。
- **占位假设不得升格为条件**：助手填的预算/时长/题量须当场标为待验证假设并复核，不得在后续文档里写成既定条件。
- **两种模式是串联而非二选一**：先设计并确认（地图、示范、材料、评价标准），再训练并按真实产物记录；“模式”只决定是否把表现记成绩。

**触发事实（如实记录）**：① 一份小测考了“交收日”，该点此前只在地图与输入表中各出现一次（都是表格一行），学习者以“没教过却考了”申诉，核查后**部分成立**；② 同一份小测的前后两题实质都压在“第四个星期三”上，学习者当场指出重叠；③ 学习者追问“12 小时预算从哪来、我有约定过吗”，核查无用户依据，系助手自行填入的占位值被后续文档沿用；④ 学习者问“为什么不先把路线、示范、材料设计好交给我看、然后再持续训练”——原措辞把两段写成并列选项。

**边界**：四条只约束“什么能考、怎么问、假设怎么记”，**不提高也不降低任何分数线**；来自单次会话的真实反馈，**不足以宣称学习效果改善**，与 v3.2.1 之间不需重新对照，基线仍是 v1.1。本次仅更新仓库源码与 WorkBuddy 副本，Trae 全局与项目级副本待版本调整结束后统一同步；不提交、不推送、不打标签。

## v3.2.5改写已有材料的保值规则

重写／精简／替换既有教学内容时：① **先问**学习者旧版「已教要点清单」**是否已学完**；② 未学完则**逐条核对**是否保留，**不得整块替换**；③ 删除须显式写「**该项退出教学**」并留痕，**不得静默消失**；④ **退出教学的点不得再进计分题**。

**"先问"这一步由学习者提出**：作者原稿只要求"删除须标注"，默认必须保留——后果是已学透的冗余会被一路滚下去。先问一次，既不静默丢失，也不逼着做无用功。

**触发事实**：一次输入因"公式未定义"作废重做（v3.2.4 来源），重写时把旧版"交易时段"整块漏掉却仍照考，学习者作答后才暴露"没教就考"；该题当场标为探测题、不计分。

**边界**：不改变任何分数线；单次会话反馈，**不足以宣称学习效果改善**；与 v3.2.4 之间不需重新对照。本次仅更新仓库源码与 WorkBuddy 副本；Trae 全局与项目级副本待版本调整结束后统一同步；不提交、不推送、不打标签。

## v3.2.4记号与公式的交付前提

新增四条交付约束，不改十步与模板结构：

- **公式三前置**：符号表（含义＋单位＋数值）→ 它要回答什么 → 一次数值走查；缺一**不得进入结论**。
- **机制须带失败场景**：给出"没有这条规则会怎样"的具体情形。
- **反例必须可算**：写出"按错误理解算出多少、差几倍"，不能只写"会错"。
- **只作了解的记号显式标注"不进考核"**；并增加**交付前自检**：通读找未定义的符号，补或删。

**触发事实**：一次小节输入在未定义 S、K、min/max 的情况下直接给公式并推结论，学习者反馈"来得太突然、完全理解不了"；同一次输入给出熔断两条件却无实例，同样被反馈"看不懂"。**该次输入被判定作废并重做**（未作答，无成绩），故本条不涉及任何成绩改写。

**边界**：不改变任何分数线；来自单次会话反馈，**不足以宣称学习效果改善**；与 v3.2.3 之间不需重新对照。本次仅更新仓库源码与 WorkBuddy 副本，Trae 全局与项目级副本待版本调整结束后统一同步；不提交、不推送、不打标签。

## v3.2.3提问台账与易混淆对照

新增两条，均落在既有机制内、不改十步与模板结构：

- **课后提问与疑问台账**：每小节末留可选提问口；问答记入进度文件的疑问台账。**提问不计分、不建 A/E、不改变状态**，只有随后的复述/追问可作证据；单元小测只从「已澄清·待复述」「仍存疑」中抽 1 题，已复述者不再抽。
- **集中输入三段结构**：核心一句 → 易混淆对照（**两列并置，各带实例与反例**）→ 常见错法及为什么错。只提醒不对比等于没教；提示中出现的内容即属"已教"，按可考性门槛可以考。

**触发事实**：① 学习者答完一节后主动追问"条文第三项算不算前两项的补充说明"——判断正确，且该问题不提出就不会被发现；② 同一节练习里学习者把"权限类别"记成"具体策略"（买入开仓→买入认购），说明只说"认购认沽都算"并不构成对照。

**边界**：不提高也不降低任何分数线；来自单次会话的真实反馈，**不足以宣称学习效果改善**；与 v3.2.2 之间不需重新对照。本次仅更新仓库源码与 WorkBuddy 副本，Trae 全局与项目级副本待版本调整结束后统一同步；不提交、不推送、不打标签。
