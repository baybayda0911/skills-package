# P2 · 经验解释与探究 · v3.0

## 目标与合格依据
用于实验、观察、调查与经验性解释，包括自然科学和实证社会研究。主张须与问题、方法、测量、数据、模型和竞争解释相匹配。区分相关、因果、预测与描述；没有唯一固定的“科学方法”序列。

## 诊断、地图与示范
查相关概念、图表、测量、变量、抽样和不确定性。按当前目标教必要内容，不一次倾倒统计术语。可先观察现象或提出问题，再展示“问题—模型—设计—数据—解释”的最小关系。

**模拟示范**：研究两种光照下同品种幼苗的生长。先明确生长指标与观察时段；在条件允许时随机分组，保持水、土、起始大小等条件可比，多株重复并统一测量。记录个体与异常，不只给组均值。若模拟均值分别为4cm和2cm，仅说明该模拟数据有组间差异；是否归因光照还取决于设计、变异与其他解释。此例尚无真实实验，不能写“光照已被验证有效”。

## 练习与反馈
引导：补一张设计表中的测量方式和需要控制/记录的条件，解释原因。独立：给另一种合理设计或检查一份故意缺陷的设计；实际可操作时提交原始记录与过程。逐步撤去变量清单、表格与分析提示。

反馈区分概念误解、测量误差、设计混淆、抽样问题和推断越界；先修只补相关部分。更精确的小数不自动意味着更可靠。

## 变式、评价与关键错误
改变测量指标、样本来源、异常数据或模型前提，检查结论如何变化。综合任务可为陌生数据解释或小型调查方案，不能只凭公式代入认证探究能力。

量规看问题与设计对齐、数据/测量可检查、分析适当、解释与不确定性、替代解释与边界。各维有示例和得分档；编造实测、严重混淆未说明却断言因果、隐去与结论冲突的关键证据属于预声明的关键错误。允许合理而不同的设计，按目标和条件评价。

## 保持、迁移与外部复核
延迟用新数据或新研究问题复验，迁移要求选择方法并解释限制。无设备、无数据或伦理/监督条件不满足时保持方案/模拟目标；未做实测与真实研究能力分开。涉及不确定分析或专业实验时找适用方法资料与领域反馈，不能靠AI自信评分。
