# 六类任务配置与组合 · v3.0

## 1. 选择规则

先问“要交什么产物，在什么条件下凭什么合格”，再选配置；不按文/理/工或学习者标签硬分。先从目标中推断，只有影响路线的歧义才澄清。主配置跟随最终产物，辅助配置服务必要子任务。

| ID | 合格依据 | 详细文件 |
|---|---|---|
| P1 形式推理与证明 | 定义、前提、推理规则及有效论证 | [P1](任务配置/P1-形式推理与证明.md) |
| P2 经验解释与探究 | 测量、数据、模型、方法与竞争解释相匹配 | [P2](任务配置/P2-经验解释与探究.md) |
| P3 文本与史料解释论证 | 主张与材料、语言、来源及语境相匹配 | [P3](任务配置/P3-文本与史料解释论证.md) |
| P4 工程设计 | 满足需求/约束，有实现与测试证据 | [P4](任务配置/P4-工程设计.md) |
| P5 沟通与互动 | 情境、受众、理解、回应与共同任务完成 | [P5](任务配置/P5-沟通与互动.md) |
| P6 创作、表演与操作 | 领域判据下的作品、过程或实际表现 | [P6](任务配置/P6-创作表演与操作.md) |

六类是可检验的产品设计，不是唯一或已经验证的学科分类。只加载选中配置。P3须再区分历史/文学/规范论证；P6须区分创作/表演/程序操作，不可共用一张泛化审美或动作量表。

## 2. 最小路由卡

每个能力ID记录：**目标产物｜主/辅助配置与子类型｜知识/表现合格依据｜先修ID｜工具/提示/环境｜要观察的证据｜评分量规/关键错误｜外部复核与未验证项**。允许先列暂定配置，诊断后依据证据修改；记录版本与理由，不重写旧成绩。

优先落实用户已声明的用途和评价条件，再匹配适用领域标准、配置建议和通用默认。若彼此冲突，评价开始前说明采用的条件、调整理由与不能推出的结论；不能以个人分数预设抵消任务关键错误，也不能用无关题型凑覆盖。

个人数值预设可继续用90/80/75；领域的核心表现另设必要判据。考试备考可叠加已核验的考试蓝图。没有可信量化方式时，先说明按维度判定而不虚构精确百分数。

## 3. 组合与调度

一个主任务可挂多个辅助能力和配置，按真实先修关系安排，不对每一能力轮流套六类。示例：
- 物理：模型推导用P1，测量与解释用P2；会推导不自动证明会实验。
- 照片整理脚本：主P4，必要逻辑用P1，用户需求访谈用P5；无运行环境不记录实测通过。
- 城市热岛提案：主P4，调查用P2，报道解读用P3，数值分析按实际任务使用P1/P2。模拟温度与虚构报道只能支持相应模拟练习，不能当实地证据。
- 外语演讲：P5看受众互动，P6看演讲表现；文字稿不证明发音、听力和现场表现。

分维度检查核心产物；辅助任务得高分不能补偿主任务关键缺陷。综合任务可对应多个能力ID，但台账逐项记录支持了哪些结论，不能重复计算成多次独立表现。

## 4. 共同十步怎样改变

第1步按配置定产物与判据；第2步查相关先修；第3步用合适表示建最小地图；第4步展示该领域的专业判断；第5步按表现撤支持；第6步观察本人独立产物；第7步改变条件与证据；第8步做陌生综合任务；第9步按保持目标重做/解释；第10步接入工具、作品与外部反馈。

需求、现象、文本或整体作品可先作简短导入，再补最小机制；有相关先修且条件适合时可短探索后教学。说明目的和支持，不把探索失败记作结业失败。来源判断、方法检查和反思从首次相关活动开始；不等到第7步才讲证据，不等到第9步才复习。
