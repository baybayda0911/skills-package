# 交互、提示与学习状态 · v2.5.2

## 1. 启动与续接

工作文件为`学习进度_<领域>.md`，使用[学习进度模板](../assets/学习进度模板.md)。每次训练先读文件；不存在则新建。记录实际时间、模式、目标、当前能力ID/单元、待答任务和下一动作，续接优先处理未完成任务，不自动从头生成试卷。

缺少文件时询问或明示未恢复，不凭记忆制造记录。文件不可写时在回复交付可复制的状态更新，并说明尚未落盘。

## 2. 提示阶梯

- 示范：可以完整讲解标准解法，说明前提、选择、检查与常见错误。
- 引导练习：先看用户已尝试和卡点，依需要给概念提示、步骤提示、部分示范；每次记录实际提示，不机械要求逐级等待。
- 独立评价：预先说明允许资料、工具和AI范围，收集用户产物；不代写解答。中途求助则切回练习并记为辅助表现，另用新任务重新检查独立性。

不把“看过示范”“复制AI产物”“在答案提示后答对”记为独立通过。

## 3. 反馈与补救

说明产物哪一处与判据不符、原因、下一次怎样改，再让用户处理不同的相关任务。区分先修不足、机制误解、程序失误、粗心和表达问题，反馈力度随错误原因调整。“理解了吗”或刚复述原答案不能替代新表现。

通常一次给一个待答任务，避免认知负担和答案泄露。允许有证据地跳过已掌握的冗余题，关键能力不跳过。多次失败先换例子、补先修或缩小目标；用户可暂停，不陷入无限同题纠错。

## 4. 能力状态（各维度可并列）

| 字段 | 什么证据才能记录 |
|---|---|
| 已接触/已讲解 | 确实呈现材料；不代表通过 |
| 提示下完成 | 产物符合本次条件，附提示类型和量 |
| 独立通过 | 在声明条件下提交符合判据的产物 |
| 延迟复验 | 间隔后新题/复述的结果、日期与条件 |
| 迁移验证 | 陌生情境的方法选择、产物与边界依据 |
| 真实工作验证 | 实际环境任务及可用外部反馈；缺少实际环境或可核实表现证据时记未验证 |

每次记录能力ID、题目摘要、原答案或产物路径、判定、错误、提示、证据依据。当前状态可以同时为“独立通过，延迟待验证”，不是一条自动递增的等级条。保留失败与改进历史；目标变更不抹去旧证据。

## 5. 复述与间隔

解释机制、因果、方法选择和失效条件；按任务选择段落、关系图、公式或示范操作。检查准确性与用户自己的理解，不把固定儿童受众当唯一通过线。选择保持目标时，可以先不看资料再复述；实际工作允许参考资料时另做有工具的任务评价。

每单元安排可调整的延迟任务，间隔按期望保持时间、提取难度和实际使用频率决定。1/3/7/14天只可作为可调示例，不是科学硬线。已讲内容仍要复验；长期中断时先用短任务确认现状，不仅问是否记得。

没有定时执行能力时只保存下次计划，不声称已自动安排提醒；用户明确要求提醒时才使用环境支持的调度能力。日后未发生的结果保持待验证。

## 6. 阶段出口

依据目标任务分别判定阶段达标，关键能力满足声明条件才可说本阶段独立任务通过。延迟、迁移和真实工作未完成时同时说明，不能以十题八过或一次复述宣布精通。用户暂停、改变用途或仅要报告也可收口，保存已观察、待验证和下次动作。

## 7. v1.1记录迁移

先保留原文件副本或原记录段，建立能力ID和目标，再把旧原答案、判定与提示信息映射进去。旧第6题与新第6步无对应关系。旧“过”若缺提示条件记“历史表现，独立性待确认”；旧已讲解只导入为讲解记录。不伪造延迟/迁移通过。来源版本仍标v1.1，迁移记录注明时间与待补证据。

## 8. 教考配比、通过线与回溯（v2.3）

### 8.1 配比随知识点层级分层

“输入∶检验”不是全局固定值，按**该知识点在本专业中所处阶段**调整：

| 知识点层级 | 输入∶检验 | 检验时点 |
|---|---|---|
| 初阶 | **8∶2** | 先集中给完整输入（地图＋机制＋示范），**层级／板块末**才整体小测一次 |
| 中阶 | **6∶4** | 讲完一个机制点即可插入检验 |
| 高阶 | **5∶5** | 边讲边验；越高阶越依赖实操确认是否真正理解 |

**理由**：层级越高越依赖实操检验。高阶没过，往往不是高阶本身的问题，而是**某个中阶知识点有漏洞**——所以需要 §8.3 的回溯。

**专项禁止**：不得跳过第5步的“跟做”与“补全”两级直接进入独立作答。跳级会把教学降级为测验，学习者会合理地反馈“一直在被考、没有新知识输入”。

### 8.2 通过线

一个知识点记“掌握”，须**同时**满足两条：

1. **能讲清机制**——用自己的话说清“是什么、为什么、哪里会错、什么条件下失效”；
2. **能独立做对**——在声明条件下提交符合判据的产物。

**检验时点可分层安排**：初阶知识点允许“讲清即前进，独立做对留到层级末小测或延迟复验”；中阶与高阶要求当场独立做对。两条不能互相替代——不以“讲清”代替“做对”，也不以“做对”代替“讲清”。

### 8.3 失败要回溯到先修层

某知识点未通过时，先判断是**本层的问题**还是**下层的漏洞向上暴露**：

```
高阶没过 → 查中阶对应先修是否稳固 → 中阶也没过 → 查初阶概念是否牢固 → 回到最早的漏洞处补
```

- 在**最早出现漏洞的层级**按 §8.1 的比例补课与重测，而不是在同一层级反复加难度；
- 记录回溯路径（哪一层漏了、补了什么、结果如何），它是进度文件里最有诊断价值的信息；
- **禁止**在同一层级无限重复同一题：换示例、补先修、缩小任务或暂停并记录。

### 8.4 提问纪律

- 凡涉及“赚／亏”“对／错”的判断，**必须写明结算时点或判断视角**（如“到期”还是“平仓”、“持仓视角”还是“市场报价视角”）；
- 凡涉及分类或比较，**必须写明以哪个视角、哪个时点为准**；
- 题干有歧义时，先修正题干再判定，**不得把理解歧义记成用户错误**。

## 9. 进度索引与里程碑（v2.5 建立 · v2.5.1 补检验体系 · v2.5.2 补通过线与顺序推进）

**要解决的问题**：学习者学了一天，却说不出"我现在在地图的哪个位置、一共走了多少、还剩多少"。教材天然带有"单元 → 大节 → 小节"的层级，学习者随时知道自己走到哪里；地图若只是一份阅读文档，就提供不了这种定位。**取消百分比不等于不需要可感知的进度——本节的索引就是它的替代物。**

### 9.1 三级索引结构

**三级结构一句话**：**大板块（里程碑）→ 中单元（一级节点）→ 小节（二级节点，最小可打勾单元）**。

地图与进度文件共用同一套编号，只有一份编号来源：

| 层级 | 名称 | 作用 | 编号示例 |
|---|---|---|---|
| 一级 | **大板块** | **里程碑**——一个完整的知识域 | `B3 定价层` |
| 二级 | **中单元** | **一级节点**——一个功能簇 | `3.2 三个维度与四条通道` |
| 三级 | **小节** | **二级节点**——最小可打勾知识点 | `3.2.4 量纲双义` |

- 编号格式 **`B板块.单元.小节`**（如 `3.2.4`）；小节是**唯一可变更状态的最小单元**。
- 每个小节挂六列：**编号｜名称｜层级（初阶/中阶/高阶）｜状态｜能力ID｜证据ID**。
- **双层映射（必须保留）**：地图坐标管**定位与感知**（刻度足够细），能力ID（T01…）管**验收与证据**（对应证据质量）。两者用同一行连起来，**不得合并成单一刻度**。
- **粒度要求**：大板块下应切出多个中单元，中单元下应切出 2~4 个小节。若某个大板块只有一个中单元、或中单元只有一个小节，说明切得过粗——**里程碑太久才出现，会失去激励作用**。
- **推进顺序＝索引顺序（v2.5.1）**：默认沿编号推进（板块按 B1→B2→…；板块内按中单元、中单元内按小节），因为索引顺序就是**先修顺序**。
  - **跨板跳跃必须留痕**：若因用户已有的证据、紧迫用途或兴趣而跳过若干小节直接进入后面的板块，必须在进度文件中记一条**跳跃记录**（跳过哪些编号、理由、是否需回补）。
  - **跳跃的后果必须说明**：跳过的先修会在高阶处暴露出来（见 §8.3 回溯）。允许先跳到用户急着用的点，但**必须同时给出"欠账清单"**——否则索引图会出现"每个板块都亮一点、却没有一条完整路径"的散点状态，学习者进而无法判断自己到底走在哪条路上。

### 9.2 状态四档与待复验标记

| 状态 | 什么证据才能记录 |
|---|---|
| **未开始** | 尚未呈现材料 |
| **已输入** | 确实呈现过材料（讲解/示范/地图）——**不等于掌握** |
| **已练** | 在提示、跟做或补全条件下完成过——**来源＝ §9.4 的小节课后练习** |
| **已通过** | 在声明条件下独立提交符合判据的产物 |

- 另设两个**并列标记**（写在状态之后，用 `·` 连接）：
  - **`待复验`**——曾独立通过，但延迟保持或迁移未验证（如"已通过·待复验"）；
  - **`部分`**——**有过独立尝试但未达判据**（如"已输入·部分"）。**必须保留这一标记**：否则一次失败的独立尝试会与"只讲过没练过"看起来一模一样，而两者的下一步动作完全不同。
- **禁止**用百分比、单一等级或连续进度条把四个状态压成一个数；总览只报**计数与当前坐标**（如"已通过 6／共 28"），不报"完成度 21%"。
- 状态只在有新证据时变更；**没有证据不得前进**，不得以"讲过"充当"已通过"。

### 9.3 进度总览条（两处必须同步）

1. **进度文件顶部固定区块**——第一眼可见，含：当前位置、各板块计数、下一站、里程碑点亮情况。
2. **每轮回复末尾一行**——形如：`当前位置：B3 定价层 › 3.2 三个维度与四条通道 › 3.2.4 ｜ 已通过 6/28 ｜ 下一站 3.3.1`。学习者不必打开文件即可感知进度。

### 9.4 三级检验体系（v2.5.1 建立 · v2.5.2 补通过线）

**每一级节点都对应一次检验**——没有检验的节点只是"走过"，不是"学会"。

| 检验 | 触发点 | 覆盖范围 | 提示条件 | 产出状态 | 频度 |
|---|---|---|---|---|---|
| **课后练习** | **每个小节末尾** | 该小节 | **允许**提示、跟做、补全 | **已练**（若当场无提示独立完成，可直接记**已通过**） | 高频（每小节 1~3 题） |
| **单元小测** | 每个**中单元**结束 | 该中单元**全部小节** | **不给提示** | **已通过** 或 附加标记 `部分` | 中频 |
| **里程碑综合测试** | 每个**大板块**结束 | 该板块全部中单元 | **不给提示** | 里程碑点亮的依据 | 低频、完整 |

**三者的分工不能混**：
- **课后练习属第 5 步**（引导练习与指导渐撤），它是**"已练"这一状态的唯一来源**——**没有它，"已练"永远是 0**，而"只被考、没被教"就会成为学习者的真实感受。练习**必须先于**独立作答（见 §8.1 禁止跳级）。
- **单元小测属第 6 步**（独立实践），是"已通过"的主要来源；必须覆盖**该单元全部小节**，不能抽一两个点就代表整单元。
- **里程碑综合测试属第 8 步**（综合评价），是点亮的依据，必须**跨小节组合**，不能只考单点。

**题型要求（里程碑综合测试）**：
- 五类题型——**概念题、判断题、填空题、计算题、应用题**——**每份至少覆盖 4 类**；
- **计算题 ＋ 应用题合计 ≥ 40%**；概念题 ＋ 判断题 ＋ 填空题合计 ≤ 60%；
- 每道题必须写明**判分点**（答到什么算过、什么是部分正确），并按 §8.4 写清结算时点或判断视角；
- 上述比例是**可调整的默认值**，来自使用体验判断，不是学习科学结论。

**通过分数线（v2.5.2）——按判分点计，不按题数计：**

| 检验 | 通过线 | 提示条件 |
|---|---|---|
| 课后练习 | **≥ 90%** | 允许提示、跟做、补全 |
| 单元小测 | **≥ 80%** | 不给提示 |
| 里程碑综合测试 | **≥ 75%** | 不给提示、跨小节组合 |

- **为什么必须按判分点算、不能按题数算**：小节的课后练习只有 1~3 题，若按题数算 90%，实际上退化成"必须全对"（2/3＝67% 不合格、3/3＝100% 合格），中间没有任何档位，分数线就失去意义。因此**每道题必须预先写明判分点**，且一节练习的**判分点总数不少于 5 点**（题少就每题多设判分点）；百分比 ＝ **得分判分点 ÷ 判分点总数**。
- **课后练习的"分数"与"状态"是两件事**：达到 90% 但**用过提示** → 记 **已练**；**无提示独立完成**且达到 90% → 可直接记 **已通过**。分数不改变提示的记账规则（见 §9.2）。
- **分数是必要条件，不是充分条件**：**含关键错误时，不论总分多高，一律判不通过**（与"不能用总体比例抵消关键错误"一致）。关键错误 ＝ 会导致实际损失或结论反向的错，例如把交割方式倒置、把盈亏平衡点当成本基数。
- **低于通过线时不必重刷整节**：按 §8.3 判断是**本层漏洞**还是**下层先修暴露**，只补涉及该判分点的内容，再用**同类新题**复核。
- 三条分数线均为**可调整的默认值**，来自学习者的使用体验判断，**不是学习科学实验结论**。

**其他约束**：
- **点亮条件**：仅当该节点下**全部小节**状态为"已通过"（或"已通过·待复验"）时才可点亮；含"部分/已练/已输入"时不得宣布达成。
- **里程碑文本只能是事实陈述**，例如"B3 定价层 8 个小节全部通过（含单元小测 3 次、里程碑综合测试 1 次），其中 2 项待延迟复验"。
- **禁止**夸张庆祝、等级、徽章、连续打卡天数等与真实掌握无关的奖励机制——它们会激励刷进度而不是掌握，也与"不得伪造用户完成记录"冲突。
- 里程碑可以给出**下一段的路线预告**（下一板块是什么、预计几个小节），这是"目标梯度"能起作用的部分。
- **检验结果要落进台账**：日期｜层级｜覆盖编号｜题型构成｜判定｜错误类型｜下一步。**只有台账里有记录的检验，才算真的做过。**

### 9.5 地图必须以"索引课程表"形式交付

第 3 步的地图**不能只是一份阅读文档**，必须同时是**索引**：

- 地图文件中带三级编号与状态列的课程表，**即进度索引表的骨架**（一份编号，两处引用，禁止各维护一套）；
- 地图交付时同步给出"共 N 大板块 / M 中单元 / K 小节"的总量，让学习者一开始就知道**边界在哪**；
- 后续增补知识点时**只能追加编号**，不改已有编号——否则历史进度与证据ID会失去对应。

### 9.6 可视化进度图（可选产物）

- 用 [进度地图模板](../assets/进度地图模板.html) 生成**一次**自包含 HTML（沿用统一 CSS 家族，颜色编码状态）；
- **首次交付生成一次即可；此后仅在用户要求时重新生成**，不每轮改写——它是产物的切片，不是过程的载体；
- 图中每个色块只承载**编号**，名称与证据留在索引表；图不得出现任何未经证据支持的状态着色。
