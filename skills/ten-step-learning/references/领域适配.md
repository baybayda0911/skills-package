# 领域适配：锚定物的选择

锚定物是**外部可核验、且门外汉用户也读得懂**的材料。它的唯一作用：把「这份报告够不够专业」从一个无法验证的主观判断，变成一个可核对的覆盖度数字。

---

## 1. 先判定领域类型

| 类型 | 特征 | 判定问句 |
|---|---|---|
| **职业型** | 有明确岗位、有资格认证或从业门槛 | 这个领域有对应的招聘岗位和从业资格考试吗？ |
| **学术型** | 是学科或理论体系，不以岗位形式存在 | 这个领域的知识主要在教材、课程与论文里吗？ |
| **商业型** | 新设业务、新兴赛道，尚无成熟职级体系 | 这个领域太新，还没有稳定的岗位名称和考试吗？ |

**混合型处理**：按主要矛盾归类，可在锚定物里混用两类来源（例如「代建拓展」→ 商业型为主 + 建筑/地产职业型为辅）。

---

## 2. 锚定物清单

### 职业型

| 来源 | 具体取法 | 抽取什么 |
|---|---|---|
| 招聘 JD | 3~5 家不同规模公司的**初级岗位** JD（不要取资深岗） | 任职要求里的可操作能力项 |
| 从业资格考纲 | 官方考纲全文 | 科目分级、知识点条目 |
| 官方教材目录 | 指定教材的完整目录 | 章节层级（天然带难度分层） |
| 协会/监管岗位说明 | 行业协会、监管机构的岗位职责文件 | 合规底线与必备能力 |

> 只取**初级岗位** JD。资深岗 JD 会把「独立带团队」「资源整合」这类非知识性能力混进来，污染任务清单。

### 学术型

| 来源 | 具体取法 | 抽取什么 |
|---|---|---|
| 课程大纲 | 2~3 所高校同专业的培养方案与课程大纲 | 课程分级、先修关系 |
| 经典教材目录 | 公认教材的完整目录 | 章节层级 |
| 综述论文 | 近 5 年高被引综述 | 领域公认的未解问题与争议 |
| 学位论文要求 | 本科/硕士的培养目标表述 | 档位分层的天然依据 |

### 商业型

| 来源 | 具体取法 | 抽取什么 |
|---|---|---|
| 行业报告 | 权威机构发布的行业研究 | 关键流程、关键指标、口径定义 |
| 从业者公开复盘 | 实操者写的复盘、访谈、公开分享 | 真实卡点、失败模式、隐性规则 |
| 监管/协会文件 | 主管部门的规范性文件 | 硬约束与红线 |
| 岗位的实践定义 | 即使无正式 JD，也可取从业者自己描述的「日常工作内容」 | 真实任务项 |

---

## 3. 抽取任务清单（15~25 条）

从锚定物里抽出「**初级从业者真实在做的任务**」，逐条写成可判断的句子：

- 每条必须是**可操作的任务**，不是「了解/熟悉/掌握」这类状态词
- 每条必须能明确判断「报告里有没有覆盖」
- 数量控制在 **15~25 条**；少于 15 条覆盖度太粗，多于 25 条用户审不动

**示例（职业型，以期权交易为例）**：

- ✓ 能读懂一张期权报价链并指出实值/虚值/平值
- ✓ 能计算一笔买入认购的到期盈亏与盈亏平衡点
- ✓ 能说明备兑开仓与裸卖看涨在风险上的差异
- ✗ 熟悉期权定价理论（状态词，无法判断覆盖）

---

## 4. 覆盖度标注与合格线

逐条标注：

| 标注 | 含义 |
|---|---|
| **覆盖** | 报告使读者能独立完成该任务 |
| **部分覆盖** | 只讲了概念，没到能做的程度 |
| **未覆盖** | 完全没有 |

未覆盖理由**只允许三类**：

1. 超出目标档位（该任务属于专家档，本次目标为专业档）
2. 属于另一分支（该任务属于本领域的另一条职业路径）
3. 确实缺失（应当覆盖但漏了——必须补写）

**合格线：覆盖率 ≥ 85%。**

防糊弄：若给出 100%，必须另列至少 3 条「边界项」说明为何算覆盖。

## 5. 领域的其它适配点

### 高风险属性

投资 / 法律 / 医疗 / 税务 → 触发合规边界（见 `证据规则.md` 第 5 节）。

### 术语密度

- 用户完全外行 → 首次出现术语时给一句话解释，之后正常使用
- 用户有相邻领域经验 → 用相邻领域做类比，但必须标注类比失效处

### 可验证性等级

某些领域的关键知识**无法被外部验证**（如管理经验、艺术判断）。此时：

- 必须显式标注「该部分无法外部验证，依据为从业者经验陈述」
- 不得把无法验证的内容伪装成有证据支持
- 反例配额在这种情况下更要靠**公开的失败案例**来满足
