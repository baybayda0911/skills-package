# 领域、先修与资源适配 · v3.3

## 1. 外部锚点与任务配置分别选择

| 标准来源 | 合适锚点 | 限制 |
|---|---|---|
| 职业 | 对应层级岗位任务、规范、资格标准、教材 | 初级JD不代表高级任务；知识考试不等于现场胜任 |
| 学术 | 课程目标、教材先修、实际研究任务 | 学科目录不自动给合格判据 |
| 商业 | 真实流程、可核验复盘和工作任务 | 单次经验不代表普遍效果 |

再按 [任务配置](任务配置.md) 选择产物与证据路径；概念、程序、判断/协作可作为能力成分，不能替代路由。高级目标补异常情境、标杆作品和专业反馈；没有外部标准时注明暂定判据与待校准部分。

## 2. 起点与先修

集中采集用途、基础、预算、工具与模式，不让零基础用户自己列完整课程。助手先提出有依据的阶段范围，由用户调整相关性和负担。

少量实际短任务查必要先修、误解与工具条件。未回答：规划记待诊断；训练暂停依赖此证据的进阶，可先给不依赖它的必要地图与导入。先分辨先修、机制、程序、题干或表达问题，不把一切失败归结为下层漏洞。

假设起点下已交付的材料记**已呈现，适配性待确认**，不记掌握；诊断后不匹配时重做或注明差异。材料呈现是事实，与是否理解分别记账。

## 3. 地图、路线与指导

默认先给最小结构、概念/流程的含义和用途，再示范和练习；不先倾倒完整手册。每单元反复使用第3—6步循环。任务配置可先用现象、需求、材料或作品导入，但随后补足必要机制。

保留三级索引作为默认展示；小节2—4个是便于定位的颗粒度建议，不为凑数拆伪知识点。稳定编号不等于先修顺序：另存先修ID与建议路线，允许并行、插入补救和已证实豁免，不重编号旧证据。

在满足必要先修的候选内容间，按当前用途、常用程度、复杂度与预算排序并给理由；不让频率越过关键先修。路线、按问题找例子与工作速查使用同一材料入口，详见[教学材料](教学材料与行动卡.md)。

指导量分别看已有知识、当前表现、复杂度与负担。初学新任务默认有示范和支持练习；已有同任务族、同条件独立证据可缩短跟做/补全，仍需目标任务证据。新情境困难时重新增援，不用题目“高阶”机械减少帮助。

## 4. 资源与现实条件

按目标选有代表性的任务族，不设固定任务数。大领域先确定阶段，其他分支列后续路线，预算到时报告真实成果与未达项，不自动升级档位。

资源分必学、执行时查阅、扩展；说明对应能力、版本、必要章节、预计负担和读后产物。没有可核实资料就标缺口，不凑数量。支持纸面、离线和有限工具路径，来源按 [证据规则](证据规则.md) 处理。

程序与操作需实际产物和过程；判断与协作需条件、反证和互动证据。纯理论不强编动手/计算。手工、设备、临床或现场任务缺实物、观察或监督时仅安排理论/模拟，真实能力仍未验证。

## 5. 表达与多解

专业术语用清晰语言解释，类比说明成立与失效处。自我解释可用文字、图示、公式或操作，按目标决定，不以口才替代能力。文学的可辩护多解、工程多方案和数学等价证明按各自判据处理。

真实相关方、角色与争议按需引入，不固定五类、不编造立场或内部消息。判断题写清适用情境、视角、范围及必要时点，先修正歧义，再评价用户。
