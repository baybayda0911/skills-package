# 设计依据、版本映射与验证 · v2.0

## 1. 范围与依据

v2.0采用用户确认的新十步顺序。技能支持研究规划与持续训练，报告展示、教学执行和学习评价分别设计。以下来源支持通用原则，不是本技能或新顺序的效果实验。没有唯一适合任意专业的科学十步顺序。

| 原则 | 原始研究/框架 | 本版本的设计推导与限制 |
|---|---|---|
| 目标—活动—评价对齐 | [Biggs，1996](https://doi.org/10.1007/BF00138871) | 第1步先定成果与判据；理论框架不自动证明AI效果 |
| 先修与认知负荷 | [Sweller等，2019](https://doi.org/10.1007/s10648-019-09465-5) | 诊断、分段、指导随知识改变；不只换话术 |
| 示范与练习交替 | [IES指南，2007](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) | 每单元示范与练习；课堂依据不直接覆盖所有成人职业 |
| 有指导的探索 | [Alfieri等，2011](https://doi.org/10.1037/a0021017) | 从支架走向独立，不能把主动学习等同无指导探索 |
| 持续提取 | [Agarwal等，2021](https://doi.org/10.1007/s10648-021-09595-9) | 检查穿插，研究不规定固定题数/通过比例 |
| 自我解释 | [Bisra等，2018](https://doi.org/10.1007/s10648-018-9434-x) | 解释因果与边界；不验证“费曼”所有形式或儿童受众门槛 |
| 间隔与保持 | [Cepeda等，2006](https://doi.org/10.1037/0033-2909.132.3.354) | 间隔依目标保持期调整；不规定统一复习日历 |
| 迁移需验证 | [Pan与Rickard，2018](https://doi.org/10.1037/bul0000151) | 新任务与条件辨别，不能从旧题成绩直接推断迁移 |
| 评价解释和切分依据 | [AERA/APA/NCME，2014](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf) | 内容覆盖与能力分开，通过线有理由与证据 |

参考这些原则改写工作指令，未复制论文、课程或第三方模板。代码与素材仍随仓库MIT许可。旧设计规范中“许可证挂起”仅是历史状态。

## 3. 对照版本

仓库标签`v1.1`保留改版前完整目录、模板和说明；标签`v2.0`保留新目录。标签是仓库版本，可能同时含其他技能；对照聚焦各标签下的`skills/ten-step-learning/`。

比较时提取两个完整目录到独立实验位置，保留MIT声明；按[交互与状态](交互与状态.md)处理旧进度，不能用新模板覆盖基线。保留用户原答案和版本、任务、工具/提示条件、时间与产物记录，敏感资料留在仓库外。

## 4. 验证分层

- 结构：frontmatter、元数据、相对引用、模板标签、编号与记录字段一致。
- 代理场景：观察模式路由、诊断等待、提示与独立评价、未来复验和旧记录迁移。用于检测指令行为，不证明真人学会。
- 真人学习：相近起点、相同预算、平行任务与尽量盲评，记录前测、即时独立、延迟新题、迁移、负担和退出。
- 职业验证：多个真实任务与相关专业人员反馈，补充文字无法评价的操作和协作。

v1.1的既有产出审计用于识别内容问题，不能当学习效果试验。v2.0亦不因研究原则、格式通过或代理演练就声称优于v1.1。真实试验前，两版均保持学习效果待验证。

## 5. 模板职责

骨架给目标、诊断状态、规划映射和4/5样品；用户确认范围与负担，不负责判定专业事实。手册保留新十章与计划/已观察分栏；研究模式完成手册不认证能力。训练逐单元更新并保存进度，未来章节可以标计划。来源超链接可保留，样式与资源自包含，占位符交付前清除。
