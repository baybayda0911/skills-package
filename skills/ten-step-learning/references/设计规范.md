# 设计依据、版本与验证 · v3.2.1

## 0. 版本编号约定

沿用2026-10-14确认的规则，历史版本不重命名，判定自上而下：
| 形式 | 条件 |
|---|---|
| X.0 大版本 | 整体结构、框架或逻辑实质改变，包括十步、模式、评价口径、索引层级或参考划分 |
| X.Y 小版本 | 新增独立功能/模块，但未命中大版本条件 |
| X.Y.Z 补丁 | 既有机制内修正规则/字段/表述，不改结构 |

历史v3.0保持十步和两模式，但改变跨任务路由、评价适配和结业/当前状态逻辑，并增加配置参考划分，命中第一条，故不是v2.6或v2.5.3。

版本命名不豁免验证。按受影响行为做结构、固定回放与独立代理检查；不要求每个补丁重做真人对照，但不能由“补丁”推断学习效果不变。效果声明需匹配真人证据，旧成绩保留当时版本、量规和条件。

## 1. 共同机制与证据边界

没有唯一适合任意专业的科学十步顺序。以下支持相关原则，不是本技能或六类配置效果试验；六类是可检验设计提案，不是完整学科分类学。

| 原则 | 来源 | 设计推导及限制 |
|---|---|---|
| 目标—活动—评价对齐 | [Biggs 1996](https://doi.org/10.1007/BF00138871) | 先定产物判据，理论不验证AI教练 |
| 先修与支持适配 | [Sweller等2019](https://doi.org/10.1007/s10648-019-09465-5) | 依已有知识与表现调支持，不只按题目层级 |
| 示范、练习与解释 | [IES 2007](https://ies.ed.gov/ncee/wwc/PracticeGuide/1) | 支持相关学习机制，不验证固定配比与完整十步 |
| 自我解释 | [Bisra等2018](https://doi.org/10.1007/s10648-018-9434-x) | 解释按任务取形式，无统一儿童受众门槛 |
| 间隔与保持 | [Cepeda等2006](https://doi.org/10.1037/0033-2909.132.3.354) | 间隔按保持目标，不规定统一日历 |
| 迁移需观察 | [Pan与Rickard 2018](https://doi.org/10.1037/bul0000151) | 陌生任务验证，不从旧题推断 |
| 评价解释与切分 | [AERA/APA/NCME 2014](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf) | 为分数/条件给理由，不提供普适90/80/75 |
| 学科实践差异 | [Shanahan等2011](https://doi.org/10.1177/1086296X11424071) | 小样本专家研究支持关注不同阅读用途，不能推广成学科刻板印象 |
| 数学来源判断的反证 | [Weber与Mejia-Ramos 2013](https://doi.org/10.1177/1086296X12469968) | 不能由有效证明判据推断数学专家不看来源 |
| 科学解释与工程设计 | [NRC 2012第3章](https://www.nationalacademies.org/read/13165/chapter/7) | 解释/设计依据不同；K—12框架不是成人技能实验 |
| 概念与程序迭代 | [Rittle-Johnson等2001](https://siegler.tc.columbia.edu/wp-content/uploads/2020/10/2001-Siegler-Alibali.pdf) | 小数学习实验不等于所有专业顺序证据 |
| 有条件先探索后教学 | [Kapur 2014](https://doi.org/10.1111/cogs.12107) | 特定数学任务，不支持所有零基础者无指导探索 |

P5、P6的具体配置主要来自目标—表现对齐与现场边界的设计推导，本轮未系统验证语言、动作及艺术教育效果，实际使用仍需相应领域标准与反馈。未复制论文、课程或第三方模板，保持仓库MIT声明。

## 2. v3.0变更与取舍（保留设计依据）

先修六类一致性：①以任务能力蓝图替代跨领域题型配额；②支持量依先修/表现，比例有预计时长口径并允许有据缩减冗余；③修评分分辨率与辅助/独立解释；④统一小节/单元/板块合取和延迟失败状态；⑤索引与先修/路线分开；⑥教学、参考解和AI评分加入核验/待复核。

再加入P1—P6可组合配置，改变示范、练习、综合评价与保持证据。数值90/80/75、三级索引、每轮定位与地图按需更新等个人偏好保留；没有以研究名义替用户另设一组“科学阈值”。原题型配额可作为声明的个人/考试预设，不再全局强制。

## 2.1 v3.1文件记忆模块

新增共享入口、学习者档案/课程索引、偏好及变更记录、课程续学摘要和合作写入校验；十步、两模式、P1—P6、评分和结业口径、三级索引层级与既有教学参考职责均不变。文件记忆参考只承载新增持久化模块，未重划原有教学/评价参考，故命中新增独立功能条款，定为v3.1，不重命名v3.0。

私有档案与课程原记录分开，索引和摘要是可重建缓存，不替代A/E台账。偏好分明示、观察和假设；跨课程引用带作用域，跨工具默认单写者。标准库保存助手只保障合作写者单文件替换，不是实时协作、跨文件事务或后台同步。没有接入Hindsight，不声称增加文件就提高学习效果。

## 2.2 v3.2开课导学模块

按2026-10-16确认的流程，新增身份/称呼入口、简短系统介绍、分轮偏好初访、课程约定及导学状态续接。它服务目标与诊断，不是第十一步/第三种模式；十步、任务配置、评分与结业逻辑、三级专业索引及既有参考职责不重划，按新增独立模块规则定为v3.2。

初访只获得个人陈述/偏好，不验证专业掌握；称呼确认不提供真实身份认证。导学介绍、认可约定、实际诊断及专业通过分别记录。默认轮次为负担预设，允许略过和按缺项续接；不把grilling的开放式穷尽访谈直接套到初学者身上，也不要求外部技能依赖。

## 2.3 v3.2.1导学通俗表达

落实2026-10-16反馈：可简短点名，随后用日常动作和贴题例子解释；第4/5/6步的含义与提示条件分别保持，通俗不等于放宽评价。系统介绍、初访、约定和模板采用同一表达要求，管理字段仍按原规则存储。属于既有机制内表述修补，按现有规则升为v3.2.1，不改十步、流程或评价逻辑。

验证使用初次开课、完整十步、第6步含义、考核与续学术语场景，保留真实助手回复并逐项检查未解释的名词、是否说清学习者动作、步骤含义及篇幅。模型模拟检查不能证明真人已理解或更有兴趣。

## 4. 验证分层

- 结构：入口/配置版本、相对引用、模板标签和必需状态字段。
- 规则：评分离散档、局部/综合冲突、延迟失败、先修插入和等价解。
- 代理：六类和混合路由是否实际改变教学/任务/评分；提示条件、未来结果与现场边界是否保留。
- 真人：相近起点、同目标预算、平行陌生任务、尽量盲评，记录独立、延迟、迁移、时间、负担和退出。
- 专业：多个真实任务和相关人员反馈，核查文字不能测到的操作与协作。

本轮对照演练只观察助手行为与隔离文件读写，不证明真人学会、真实Codex/Trae界面兼容或新版学习效果优于基线。结构检查不能替代代理演练，单次代理演练不能替代真人研究。源码说明只记可复现的方法与边界，原始演练放独立管理位置。
