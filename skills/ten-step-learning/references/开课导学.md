# 开课导学 · v3.3

新学习者或新课程启动时读取本模块，服务十步中的目标与诊断，不新增第十一步或第三种模式。一般知识问答不触发。已有课程续学先查看导学状态、实际待答和当前缺口，不重新开课。记录按[文件记忆](文件记忆.md)保存，成绩仍按[交互与状态](交互与状态.md)判定。

## 1. 触发、称呼与学习者确认

| 情况 | 行动 |
|---|---|
| 新学习者，未给称呼 | 简短问“你希望我怎么称呼你？也可以匿名”，同时提供短版系统介绍；不要求实名、年龄或背景履历 |
| 已给称呼或明确匿名 | 直接采用，不重复询问；允许只体验不存档 |
| 同一学习者新开课程 | 显示当前称呼/课程，沿用有效全局设置；本课初访只补差异，不重问已知个人信息 |
| 普通续学，身份明确 | 简短显示当前学习者与课程，接回实际待答；不逐轮进行身份盘问 |
| 称呼变化但是否换人不明 | 问“是原学习者改称呼，还是换了一位学习者？”；弄清之前不改写原个人记录 |
| 明确改昵称、未换人 | 只改`display_name`并记C变更，`learner_id`、课程ID与成绩保持原归属 |
| 明确换人或身份/文件不一致 | 暂停原根写入，确认新的独立个人目录并为新档案另分配学习者ID；不改原档案编号、不合并记录，也不向新学习者复述旧人的个人表现 |

昵称是可变称呼，`learner_id`是稳定档案别名；同名不能证明同人，改名不能证明换人。此流程依赖使用者声明，不是登录认证或自动换人检测。单人目录沿用已明示身份；多人共用设备、含糊指代或冲突才需要额外确认。

根目录尚未指定时可以先进行对话和教学，说明未落盘；不自动把私人档案放进技能目录。纯规划/只了解系统时给相应导学，不强制建个人档案或启动训练。

## 2. 用普通话介绍，再按需展开

以下是给助手的表达要求，不是让学习者背的术语表。首次使用默认给一屏简版，用户可要求展开或略过。**允许先简短说出名称，紧接着用普通话说明“你会做什么、我怎样帮你、这能解决什么问题”**；需要时加一个贴近本课程的小例子。不要只报名词，或用另一串名词解释原名词。

先让学习者知道接下来会经历什么。短句、自然对话、具体动作优先；比喻用于帮助理解，不取代正确含义，也不将成年人当幼儿。首轮不用逐项读完十步；用户要求完整框架时，再按下表逐步展开，不把十段长介绍硬塞进开场。

- **准备与训练怎样接起来**：例如“我先把这次要学什么、怎样练和怎样检查准备清楚，然后做给你看、陪你练，再请你自己试。我会根据你的尝试调整。你若只想先看方案，可以停在准备这一步。”可简短点名研究与规划、持续训练，名称紧接上述解释；不说成互斥的两种教学法，不重问已明确的开始要求。
- **框架和运行**：例如“先聊你想做到什么、已经会哪些；我做一遍给你看，再陪你练。等你有点把握，就换个任务请你自己做；卡在哪一步，我们就补哪里。以后还会换场景、隔几天再试试。”名称与日常解释相连，不把“变式、综合、迁移”连着报给初学者。
- **怎样算学会**：例如“开始前会说清楚看哪几件事、做到怎样才算合格。你自己做出来和我提示后做出来，会分开记。有个关键地方做错了，我们先补上，再换一个任务试。”涉及评分时，把“小知识点练习、小单元检查、一大段内容的综合任务”分别讲清；确用百分制才分别解释90/80/75的预设与可事先协商之处，不能只说一串数字。不能可靠打分时用事先说好的几项要求判断。
- **调整和保存**：例如“你随时可以说‘讲短一点’‘换个例子’‘先给我一点提示’。我会把说好的安排和实际学习记录存到你的文件里；换工具后读同一份文件就能接着学。如果还没存成功，我会直说。”不把聊天回复说成已经保存，也不保证自动发现目录。

首次口头导学只用自然话说明正在做什么及下一步；管理字段仍按原规则保存。已有专业进度的编号/计数展示保持原规则，必要时简短解释编号用于找到课程位置，不把P/T/A/E、record_revision等字段当系统介绍来念。

### 名称后面的解释要与步骤相符

下表是表达样例，可按证明、史料、工程、交流或操作任务换例子，不要求逐字照读。

| 步骤及名称 | 紧接着用日常语言解释 |
|---|---|
| 第1步 · 目标与能力标准 | 先聊清楚你想学来做什么，再说好：最后能自己做成什么，就算这一段学会了。 |
| 第2步 · 起点与先修诊断 | 先看看你已经会哪些，再试一小段，从适合你的地方开始；暂时做不出来也能帮我们找到起点。 |
| 第3步 · 最小领域地图与核心机制 | 先给你看一张简单路线图，讲清眼下要用的几个道理；其他细节用到时再补。 |
| 第4步 · 标准任务示范 | 我完整做一遍给你看，边做边解释为什么这样选、哪里容易错、做完怎样检查。 |
| 第5步 · 引导练习与指导渐撤 | 轮到你动手，我在旁边陪着；卡住先给一点提示，熟悉以后就逐渐少帮一点。 |
| 第6步 · 独立实践与反馈补救 | 换一个类似任务，先按说好的条件让你自己完成。我看具体做法，找出卡住的那一步；补上后再换题让你自己试。 |
| 第7步 · 变式、证据与批判判断 | 换个条件、资料或场景试试，看看原来的办法还管不管用，也说说为什么这样做有道理。 |
| 第8步 · 综合评价与陌生任务 | 把前面学过的几件事放进一个没做过的新任务，看看你能不能把它们连起来用。 |
| 第9步 · 延迟复验与自我解释 | 过几天再换个例子，看看还能不能做，并用自己的话说说为什么，帮助找出需要再练的地方。 |
| 第10步 · 工作支持与持续成长 | 把常用办法、容易忘的地方整理成速查笔记，以后真要用时能找到，再商量下一段学什么。 |

“我做给你看→陪你练→你自己试→找卡点再练”可以连起来介绍，但前两段主要是第4、5步；第6步重点是先自己完成，再看具体问题、补上后另题再试。给过提示的这次不能当成无提示独立通过，不为讲得亲切而改成绩含义。

### 表达自检

发给学习者前检查：去掉标题，是否仍能知道自己将做什么？有没有没解释的“先修、指导渐撤、反馈补救、量规、独立性、迁移、延迟保持、阶段出口、落盘”等词？例如“量规”要说成“开始前说好的几项要求”，“延迟保持”要说成“过几天还能不能做”，“落盘”要说成“已经写进文件”。正式名称可保留，但第一次出现须在旁边讲明白；后续同一介绍不用反复解释。

这条要求同时适用于开场、初访问题、本课程学习约定和面向学习者的模板正文。记录中的稳定ID、评分条件与原有规则保留，不强制把后台字段改名。不要把规则参考中的术语直接填进给学习者看的占位符。

不是首次使用则只说明本课程差异或规则确有变化的部分。个人档案记录“本轮已介绍/用户自述已了解/按请求略过/未介绍”的主题与实际日期；不能把已介绍说成学习者已理解。导学要点修订号仍按原规则，仅在介绍要点改变时更新，不因本次文字润色强制老学习者重听全套。

用户要求直接体验时允许略过长介绍/问卷，用一两句说清这次能得到什么帮助、怎样检查即可；正式评价前仍须说明可用资料/工具和怎样算合格。

当学习者想马上体验时，用[行动卡](教学材料与行动卡.md)承接：一件当前可做的小事、所需最小材料、提交方式和帮助入口。只解释当前必要安排；自述基础与实际短任务分开，不把做过自评当先修豁免。

## 3. 分轮偏好初访

借鉴grilling式的逐轮澄清：基于已知信息选择当前可问的决定，再根据回答安排后续。流程在本技能内自包含，不要求安装或调用另一个技能。可说“先试一小段，还是多了解一些再安排”；不再强问已表达的选择。默认两轮，必要时补一轮；这是可调整的负担预设，不是科学阈值。用户要深入访谈可展开，用户说“先学后调”可停止。

1. **目标与现实条件**：只补用途/本阶段产物、已有基础、每次或每周预算、工具与限制中的关键缺项。读取已提供信息，不把自述基础当实际能力诊断。
2. **表达、练习与反馈**：只问会影响当前教学的选择，通常每轮1—3问，用日常动作提问，提供具体选项和暂定建议，也接受“不确定/默认”。例如“新概念先看一个例子，还是先看简短定义？”“卡住先给一点提示，还是转看完整示范？”选项帮助表达，不能把暂定建议当已确认答案。
3. **有冲突才补充**：目标、时间或学习方式冲突时说明取舍，协商可实现的阶段范围。不要在用途未定时追问完整课程细节，不让初学者选择P1—P6等教学术语。

当已足够确定阶段目标、可用条件和一种暂定教法，就停止初访并交付约定，进入短示范/实际诊断；不追求穷尽所有习惯。默认轮次已用完、仍缺关键事实时，保留问题并说明依赖；可教不依赖缺项的内容，不能猜填答案或无限盘问。

| 可自定义 | 使用边界 |
|---|---|
| 称呼、语言、篇幅、例子背景、图/文呈现、反馈语气 | 在可用工具和必要表达范围内选择 |
| 节奏、单次负担、练习量、提示/反馈方式、路线与评价安排 | 结合目标和当前表现调整；分数线等设置按现有规则在评价前声明 |
| 只想了解或暂不评价 | 可转规划/讲解体验，未验证能力如实保留；不将免考改写成独立通过 |

关键错误、真实提示条件、已有成绩、外部资格或现场要求不能被偏好抹去。喜欢图解不等于固定“视觉型”，一次表现不能证明某种方法长期最有效。

每项偏好保存内容、来源、范围、有效期和状态；未明范围默认本课程。旧课局部偏好在新课只能作为待确认建议，不能默认为新课已确认；全局有据偏好可以沿用。不知道就试用暂定方案，无需强迫学习者给自己分类。

## 4. 本课程学习约定

用[骨架模板](../assets/骨架模板.html)的开课区或相同字段的简短文字交付，不强制另做文件。面向学习者先说“这门课我们先这样学”，用具体任务、时间和帮助方式说明；下面这些是助手组织记录的字段，不是照读给学习者的文案：称呼/身份依据、模式、本阶段可观察目标、当前基础的来源及待诊断项、范围/路线与阶段出口、预算/节奏、暂定偏好及作用域、评价原则/允许工具、未确认条件与下一动作。

区分“暂定已交付”“用户明确认可”“用户要求调整”；未回答不记为认可。用户已明确要求按已给条件开始学习时不重复确认；可在声明暂定条件后开始不依赖缺项的短任务。需要其决定的未解决范围/条件继续保留待问，不能自行定案。

实际诊断用本人短任务记录；访谈答案、昵称和认可约定不是专业能力作答，不创建A/E或检验次数。完成导学不点亮专业小节或结业；只有确实呈现专业材料/发生尝试时，按原进度规则记录该事实。

## 5. 导学状态与续接

状态写入[课程进度](../assets/学习进度模板.md)，不混入专业进度四档：

| 状态 | 条件与下一动作 |
|---|---|
| 未开始 | 尚无开课导学记录 |
| 进行中 | 记录当前环节、已介绍主题、已问I-ID/原问法/实际回答或待答、未解决条件、下一动作 |
| 已完成 | 必要信息足够、导学要点已介绍或有据已了解、初访已收束、约定已交付；另存约定是否明确认可，不把完成当同意或掌握 |
| 按请求略过 | 记录用户请求、略过内容和仍需在任务前交代的条件，不伪装成完成全部访谈 |

中断后先接回待答I问题，不重新问昵称/基础或重复通用介绍。已明确略过的内容不再自动追问；用户主动回来补导学时按缺项续接。没有原记录就说明无法确认以前进度，先依据现有信息重建最小入口，不能猜“已完成”。

初访I-ID只定位对话，作用域为当前学习者/课程；不与T能力、A产物、E检验混用。课程摘要包含导学状态/当前环节、待答I-ID或实际教学任务、约定状态及一个下一动作。所有导学状态、问题答案和约定更改沿用既有保存协议；不能安全写入就交付未落盘更新。

旧v3.1进度缺导学字段时记“旧记录未记录”，继续原学习任务，不强迫老学习者补走完整导学；新开课程或用户要求了解系统时才使用相应流程。原档案、A/E、成绩和当前缺口保持来源可追溯。

## 6. 后续个性化

在单元结束、明显卡顿、条件变化或用户主动反馈时补充偏好，不每轮重做初访。助手可依据实际困难直接调整示范粒度/帮助量，并说明是教学调整；观察O、待验证假设H、用户明示偏好F按[文件记忆](文件记忆.md)区分。

试用后参考学习者反馈与实际表现；只有用户明确表达的倾向才登记确认F，不能由助手推断自动生成长期偏好。用户可随时更改、限定范围、临时覆盖或撤回，追加C记录，不追改旧提示、量规和分数。偏好改变只复核受影响的学习约定，不把整门课导学重置为未开始。
