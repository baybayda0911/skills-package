# 证据、准确性与适用边界 · v3.3.1

## 1. 知识证据与学习表现分开

知识依据回答“这个结论为什么可信”；学习评价回答“用户在记录条件下能做到什么”。课程质量不证明用户能力。来源检验不能用人的测验成绩替代，能力判据也不产生知识结论的可靠性评分。

## 2. 按断言类型找证据

| 断言类型 | 优先依据 | 注意事项 |
|---|---|---|
| 规范、标准、产品行为 | 适用版本原文、主管机构/实现文档 | 确认生效范围和版本；规范不证明实际效果 |
| 因果效果、比较 | 合适原始研究或研究综合 | 方法、样本、比较组、结果与不确定性；不能只看发布方 |
| 机制、公式、定义 | 可靠教材、推导、标准定义或原始论文 | 前提、单位、约定和失效条件 |
| 工作经验、案例 | 可核验过程、原始记录、从业者材料 | 单案例不能代表普适效果；利益立场与选择偏差 |
| 设计建议、模拟 | 清楚标注推导/自定/模拟 | 不伪装成事实、已发生用户表现或真实案例 |

评估来源相关性、方法质量、独立性、时效、冲突和适用条件。不同网页转述同一数据不构成独立交叉验证；权威域名和数量都不能自动给10/7/4/1分。

## 3. 证据卡

关键断言记录：类型｜结论｜直接来源与版本｜为何支持｜限制/反证｜待确认信息。需要用“较强/有限/不确定”时写明理由。争议不存在则说明共识和证据限制，不硬凑反方。

关键事实、规范、公式、时效性、效果或争议用内联编号[n]绑定文末出处；同一连续解释可在相关段末引用，避免对每个过渡句重复角标。建议和示例显式标注。核对页面内容是否支持断言，不只核对链接能打开。

不设固定官方/教材/经验/反向材料比例。依据实际问题选择合适材料，检查是否遗漏重要反证。数值和年份需有用途，不填无关数字以凑深度。

## 4. 无联网或来源不足

给已知且能确认的作者/书名/关键词/机构/年份等检索线索，并标“待核实”；不能编造URL、书籍、编号、日期或样本。缺口影响关键结论或评分答案时降低范围，暂不做该能力的通过判断。

访问受限与失效区分：登录墙、403或反爬不等于文件不存在；可注明未独立核验并找合法替代来源。只读摘要时不宣称已核对全文的方法与数据。

## 5. 教学、参考答案与评分准确性

来源可查只是起点，不能证明AI解释、推导、模拟或评分正确。示范与评价都要核对前提、过程和结论；计算核单位和推导，代码在可用且获授权环境核结果，文本解释核引文与语境，操作/互动核可观察表现。

评价前准备教师记录：目标与条件、核验过的参考/多种等价解、量规得分档、典型边界答案和关键错误。独立评价时不提前交付参考；反馈需逐项指向用户原产物与判据，不能仅说“参考答案不同”。正确结论配错误论证仍需纠正，合理等价解不能误判。

自检或第二次AI检查仍是内部核对，不冒称独立专家认证。对高阶、争议、多解或现场能力，列出需要的专业/受众/实际环境复核。没有相应证据时标**评分待复核**与受影响能力，不让不确定分数作为关键先修放行，也不全盘否定其他已核实表现。

维护时用原始示例、故障答案和多种有效解核查：讲解正确性、误判/漏判、不同表达的一致性、任务与评分对齐。版本与复核条件写入演练记录。结构通过、来源充足或AI互相赞同，都不证明评分已校准或真人学会。

教师样题、等价解和反馈回看位置可用[任务卡](../assets/教师任务卡模板.md)关联原材料版本。完整配套样例不等于已运行结果，题库称“实用”不等于实操证据；材料修订/退出须同步检查题目，预先核验与实际作答分开记录。

### 具体题目、原图与评价纠错

核题干、答案/等价解与量规是否共同受当前来源或推导、测试、约束支持；外部资料定位到页/节/图或稳定段落。来源冲突、版本变化或局部证据只支持局部结论；教材原文、AI解释/推导与未核实信息分别标明，不用相似措辞或关键词吻合代替实质判断。

原图任务须真正读取相应原页/图像，确认图例、坐标、裁剪范围与可读性。正常任务输入与泄答线索按事前条件区分；生成示意图不能充当原图。缺图或识别/参考键不确定，先补证据或缩小评价范围。

逐维区分有效部分、确实错误与暂不能判断：等价表达可接受，部分不等于全错；来源不足、题意歧义、工具失败或答案键不可靠，不形成该项负面能力证据，也不凭不确定结果放行。模型自报置信度不是已校准概率，不设通用0.8可靠线。申诉核查及A/E关联更正按[交互与状态](交互与状态.md) §3；教学问题先修材料，不能只要求学习者重做。

## 6. 高风险与现场能力

投资、法律、医疗、税务的个体真实决策保持学习和模拟定位，注明边界，避免生成可直接执行的个体操作指令。历史数据、假设数值和规范细节有教学需要时，写清情境与来源，不能把模拟转成具体个人建议。需要资格、设备或专业监督时列出外部验证条件。

角色立场、利益和所谓隐性知识有依据才写；不能编造访谈、现场经历或用户完成记录。私人资料和学习原答案保存在用户工作目录，示例对外共享先脱敏。
