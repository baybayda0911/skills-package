# 证据规则与合规边界

---

## 1. 内联角标（强制）

- 每条**事实性断言**必须带内联角标 `[n]`，与文末「参考来源」编号对应
- 无来源的句子必须**显式标注**为「推断」「经验判断」或「待验证」
- **来源不许只堆在文末**

v1.0 实测的两种形态（同一 skill 跑出两种引用纪律，即「质量不稳定」的具体形态）：

| 报告 | 正文内联角标 | 文末来源 |
|---|---|---|
| 股指期权 | 有 `[1]~[12]` | 12 条 |
| ETF 期权 | **0 条** | 9 条 |

判定：ETF 那份的读者无法知道「备兑适合新手」这句话该信哪一条来源——**来源与断言没有绑定**，等于没有引用。

---

## 2. 来源品类配额（强制）

| 品类 | 占比下限 |
|---|---|
| 官方 / 一手文件（监管文件、交易所规则、原始数据、标准原文） | **≥ 40%** |
| 经典教材或公认书籍 | **≥ 20%** |
| 从业者一手材料（访谈、复盘、交易日志、内部讲义） | **≥ 20%** |
| 反向材料（失败样本、监管处罚、争议与批评） | **≥ 10%** |

### 为什么要有品类配额（重要）

v1.0 实测：21 条来源**全部**是交易所与证监会官方文件（20 中文 + 1 英文站），教材 0 条、从业者一手 0 条、失败样本 0 条。

后果不是「来源不权威」，而是**来源的品种只有一个**，导致报告只能长成「规则摘要 + 由规则衍生的推理」：

- 官方文件回答：规则是什么、怎么合规
- 官方文件**不**回答：什么时候会亏、哪种做法在实盘被证伪、内行靠什么判断

**权威性满分，实践性为零。** 而「专业平均水平以上的判断力」恰恰来自后一半。

> 注意：不要因为「官方文件更可靠」就全部堆官方文件。可靠性由角标保证，**品类由配额保证**，两者是不同维度。

---

## 3. 降级分支（无联网能力时）

- **降级为检索式**：书名 + 作者 + 版次 / 关键词 + 文件编号 + 发布机构 + 年份
- 每条必须显式标注「**待核实**」
- **禁止凭印象补链接**，禁止编造 URL、书名、文件编号、发布日期

无法确认某条来源是否存在时，宁可写成检索式并标「待核实」，也不得写出一个看似具体的链接。

---

## 4. 来源有效性核验（有联网能力时）

生成参考来源后，建议核验：

- 逐条实测可达性，区分「**失效**」（4xx/5xx/DNS 失败）与「**不可判定**」（403、反爬、登录墙、地域限制）——**两者不可混为一谈**
- 检查「**不对版**」：链接能打开，但落地页与锚文本所指明显不是一回事
- 检查锚文本与落地页标题是否一致

> 参照数据：v1.0 两份报告的 21 条链接实测为 **21/21 存活、0 编造、0 不对版**，且全部落在官方域。这说明**本引擎在来源真实性上表现良好，不需要靠禁止写链接来防**——真正要防的是「没钉在断言上」和「品类单一」。

---

## 5. 合规边界（高风险领域强制）

涉及**投资 / 法律 / 医疗 / 税务**时：

### 必须做

- 报告含明确**免责声明**（「不构成投资建议」等对应领域表述）
- 明确区分：事实 / 推断 / 经验判断 / 待验证
- 主动给出反例与失败案例

### 禁止做

- 具体标的代码、合约代码
- 具体价位、目标价、止盈止损价位
- 仓位数字、资金分配比例
- 买卖时点与操作指令

### 降级改写句式（保住可输出路径）

不要因为合规把整块内容砍掉，而是**把「操作指引」改写成「判断维度」**：

| ✗ 禁止写法 | ✓ 降级写法 |
|---|---|
| 该买哪个执行价 | 该用哪几个维度筛选执行价 |
| 什么时候该平仓 | 哪些信号出现时应重新评估仓位 |
| 配多少仓位 | 影响仓位决策的变量有哪些 |
| 该做买方还是卖方 | 买方与卖方的盈亏结构差异在什么条件下会反转 |

**允许**：方法论、判断维度、结构对比、模拟推演、纸面演练、历史复盘。

> 参照数据：v1.0 两份报告在这一点上做对了——全篇无具体合约代码、行权价数值、仓位数字或止盈止损价位，只做模拟推演。但**合规声明存在代际差异**（股指那份写了「不构成投资建议」，ETF 那份没写），这种不确定性本身就是 bug。本规则的作用是把它固定下来。

---

## 6. 不确定性的正确表达

- 证据不足时，写「**目前证据不足以判断 X，需要 Y 才能确认**」，而不是含糊其辞
- 明确写出**反方最强论证**，不能只写立场的支持证据
- 每条结论标注**适用边界**：在什么条件下成立、什么条件下失效
