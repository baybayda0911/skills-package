# 自动化与工作流程补充

适用于重复工作、文件整理、团队协作、运营流程及定时执行的构思。先判断流程是否稳定和值得自动化，不默认增加脚本或定时任务。

## 优先澄清

- 当前是谁在什么时机做哪些步骤，最耗时或最易错的是哪里。
- 由手动、事件还是时间触发；工作日、时区和截止条件是否重要。
- 输入来自哪里，怎样识别已处理、未处理和无效内容。
- 重复执行会不会重复发消息、重复生成或覆盖资料。
- 中途失败、资源不可用、设备离线或负责人缺席时怎么办。
- 是否需要审批、人工复核、通知和补救；不要默认允许对外发送。
- 完成后怎样知道成功，怎样暂停、取消或恢复。

## 先描述一条完整路径

```text
开始条件 → 检查输入 → 执行核心步骤 → 核对结果 → 通知或交接
异常路径 → 保留现场 → 记录失败 → 重试或人工处理
退出路径 → 停止后续动作 → 说明已完成部分 → 恢复或撤回
```

## 方案补充字段

- 执行者、触发条件、处理范围和明确排除项。
- 输入、输出、保留期限与访问权限。
- 重复执行、覆盖、删除和失败重试的规则。
- 各交接步骤的负责人及完成标准。
- 记录与通知内容，避免写入凭据或私人资料。
- 手动试跑、模拟演练和真实执行分别记录。

定时、安装、对外通知、付费服务和删除行为是不同授权对象。没有授权时只设计，不创建或启用实际任务。
